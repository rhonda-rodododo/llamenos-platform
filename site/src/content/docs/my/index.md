## ဗိသုကာ ခြုံငုံသုံးသပ်ချက်

Llamenos သည် **Cloudflare Workers** သို့မဟုတ် **Docker Compose / Kubernetes** မှတစ်ဆင့် သင့်ကိုယ်ပိုင် အခြေခံအဆောက်အအုံပေါ်တွင် လုပ်ဆောင်နိုင်သော single-page application (SPA) တစ်ခုဖြစ်သည်။ ၎င်းသည် အသံခေါ်ဆိုမှုများ၊ SMS၊ WhatsApp နှင့် Signal တို့ကို ပံ့ပိုးပြီး — ၎င်းတို့အားလုံးကို ပေါင်းစည်းထားသော အင်တာဖေ့စ်တစ်ခုမှတစ်ဆင့် အလုပ်ချိန်ရှိ စေတနာ့ဝန်ထမ်းများထံ လမ်းကြောင်းပေးသည်။

| အစိတ်အပိုင်း | Cloudflare | ကိုယ်တိုင်အိမ်ရှင် |
|---|---|---|
| Frontend | Vite + React + TanStack Router | အတူတူ |
| Backend | Cloudflare Workers + 6 Durable Objects | Node.js + PostgreSQL |
| Blob သိုလှောင်မှု | R2 | RustFS (S3-compatible) |
| အသံ | Twilio, SignalWire, Vonage, Plivo, သို့မဟုတ် Asterisk | အတူတူ |
| မက်ဆေ့ချ်ပို့ခြင်း | SMS, WhatsApp Business, Signal | အတူတူ |
| Auth | WebSocket သော့တွဲများ (BIP-340 Schnorr) + WebAuthn | အတူတူ |
| ကုဒ်ဝှက်ခြင်း | ECIES (secp256k1 + XChaCha20-Poly1305) | အတူတူ |
| စာသားမှတ်တမ်းပြောင်းခြင်း | Client-side Whisper (WASM) | Client-side Whisper (WASM) |
| i18n | i18next (ဘာသာစကား ၁၃ မျိုး) | အတူတူ |

## အခန်းကဏ္ဍများ

| အခန်းကဏ္ဍ | ကြည့်ရှုနိုင်သည် | လုပ်ဆောင်နိုင်သည် |
|---|---|---|
| **ခေါ်ဆိုသူ** | ဘာမှမရှိ (ဖုန်း/SMS/WhatsApp/Signal) | ဟော့လိုင်းသို့ ခေါ်ဆိုခြင်း သို့မဟုတ် မက်ဆေ့ချ်ပို့ခြင်း |
| **စေတနာ့ဝန်ထမ်း** | ကိုယ်ပိုင်မှတ်စုများ၊ တာဝန်ပေးထားသော စကားပြောခန်းများ | ဖုန်းဖြေခြင်း၊ မှတ်စုရေးခြင်း၊ မက်ဆေ့ချ်များကို တုံ့ပြန်ခြင်း |
| **တင်ပြသူ** | ကိုယ်ပိုင်အစီရင်ခံစာများသာ | ဖိုင်ပူးတွဲမှုများပါရှိသော ကုဒ်ဝှက်ထားသည့် အစီရင်ခံစာများကို တင်သွင်းခြင်း |
| **အက်ဒ်မင်** | မှတ်စုများ၊ အစီရင်ခံစာများ၊ စကားပြောခန်းများ၊ စစ်ဆေးမှတ်တမ်းများ အားလုံး | စေတနာ့ဝန်ထမ်းများ၊ အချိန်ဇယားများ၊ ချန်နယ်များ၊ တားမြစ်မှုများ၊ ဆက်တင်များကို စီမံခြင်း |
