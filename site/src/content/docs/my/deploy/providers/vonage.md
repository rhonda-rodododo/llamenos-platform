---

Vonage (ယခင် Nexmo) သည် ခိုင်မာသော နိုင်ငံတကာလွှမ်းခြုံမှုနှင့် ယှဉ်ပြိုင်နိုင်သော စျေးနှုန်းများကို ပေးဆောင်သည်။ ၎င်းသည် Twilio နှင့် ကွဲပြားသော API မော်ဒယ်ကို အသုံးပြုသည် -- Vonage Applications သည် သင့်နံပါတ်၊ webhook များနှင့် အထောက်အထားများကို အတူတကွ စုစည်းပေးသည်။

## ကြိုတင်လိုအပ်ချက်များ

- [Vonage အကောင့်](https://dashboard.nexmo.com/sign-up) (အခမဲ့ခရက်ဒစ်ရရှိနိုင်ပါသည်)
- သင့် Llamenos အင်စတန်းကို အများသုံး URL တစ်ခုမှတစ်ဆင့် ဝင်ရောက်နိုင်ရန် ဖြန့်ကျက်ထားရန်

## 1. Vonage အကောင့်ဖွင့်ပါ

[Vonage API Dashboard](https://dashboard.nexmo.com/sign-up) တွင် စာရင်းသွင်းပါ။ သင့်အကောင့်ကို အတည်ပြုပြီး dashboard ပင်မစာမျက်နှာမှ သင့် **API Key** နှင့် **API Secret** တို့ကို မှတ်သားပါ။

## 2. ဖုန်းနံပါတ်တစ်ခုဝယ်ပါ

1. Vonage Dashboard တွင် **Numbers** > **Buy numbers** သို့ သွားပါ
2. သင့်နိုင်ငံကိုရွေးချယ်ပြီး **Voice** စွမ်းဆောင်ရည်ရှိသော နံပါတ်တစ်ခုကို ရွေးချယ်ပါ
3. နံပါတ်ကို ဝယ်ယူပါ

## 3. Vonage Application တစ်ခုဖန်တီးပါ

Vonage သည် ဖွဲ့စည်းမှုကို "Applications" များအဖြစ် အုပ်စုဖွဲ့သည်:

1. **Applications** > **Create a new application** သို့ သွားပါ
2. အမည်တစ်ခုထည့်ပါ (ဥပမာ "Llamenos Hotline")
3. **Voice** အောက်တွင် ၎င်းကိုဖွင့်ပြီး အောက်ပါတို့ကို သတ်မှတ်ပါ:
   - **Answer URL**: `https://your-domain.com/api/telephony/incoming` (POST)
   - **Event URL**: `https://your-domain.com/api/telephony/status` (POST)
4. **Generate new application** ကိုနှိပ်ပါ
5. အတည်ပြုစာမျက်နှာတွင် ပြသထားသော **Application ID** ကို သိမ်းပါ
6. **private key** ဖိုင်ကို ဒေါင်းလုဒ်လုပ်ပါ -- သင်သည် ၎င်း၏အကြောင်းအရာများကို ဖွဲ့စည်းမှုအတွက် လိုအပ်မည်ဖြစ်သည်

## 4. ဖုန်းနံပါတ်ကို ချိတ်ဆက်ပါ

1. **Numbers** > **Your numbers** သို့ သွားပါ
2. သင့်ဟော့ပ်လိုင်းနံပါတ်ဘေးရှိ ဂီယာအိုင်ကွန်ကိုနှိပ်ပါ
3. **Voice** အောက်တွင်၊ အဆင့် 3 တွင် သင်ဖန်တီးထားသော Application ကိုရွေးချယ်ပါ
4. **Save** ကိုနှိပ်ပါ

## 5. Llamenos တွင် သတ်မှတ်ပါ

1. အက်ဒ်မင်အဖြစ် ဝင်ရောက်ပါ
2. **ဆက်တင်များ** > **တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူ** သို့ သွားပါ
3. ဝန်ဆောင်မှုပေးသူ dropdown မှ **Vonage** ကိုရွေးချယ်ပါ
4. အောက်ပါတို့ကို ထည့်သွင်းပါ:
   - **API Key**: Vonage Dashboard ပင်မစာမျက်နှာမှ
   - **API Secret**: Vonage Dashboard ပင်မစာမျက်နှာမှ
   - **Application ID**: အဆင့် 3 မှ
   - **Phone Number**: သင်ဝယ်ထားသော နံပါတ် (E.164 ပုံစံ)
5. **သိမ်းရန်** ကိုနှိပ်ပါ

## 6. သတ်မှတ်မှုကို စမ်းသပ်ပါ

သင့်ဟော့ပ်လိုင်းနံပါတ်ကို ခေါ်ဆိုပါ။ ဘာသာစကားရွေးချယ်မှုမီနူးကို သင်ကြားရမည်ဖြစ်သည်။ ခေါ်ဆိုမှုများသည် အလုပ်ချိန်အတွင်း စေတနာ့ဝန်ထမ်းများထံ လမ်းကြောင်းပြောင်းပေးကြောင်း စစ်ဆေးပါ။

## WebRTC သတ်မှတ်ခြင်း (ချန်လှပ်နိုင်)

Vonage WebRTC သည် သင်ယခင်က ဖန်တီးထားပြီးသား Application အထောက်အထားများကို အသုံးပြုသည်:

1. Llamenos တွင် **ဆက်တင်များ** > **တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူ** သို့ သွားပါ
2. **WebRTC ခေါ်ဆိုခြင်း** ကို ဖွင့်ပါ
3. **Private Key** အကြောင်းအရာများကို ထည့်သွင်းပါ (သင်ဒေါင်းလုဒ်လုပ်ထားသော ဖိုင်မှ PEM စာသားအပြည့်အစုံ)
4. **သိမ်းရန်** ကိုနှိပ်ပါ

Application ID ကို ကြိုတင်သတ်မှတ်ပြီးဖြစ်သည်။ Vonage သည် ဘရောက်ဆာအထောက်အထားစစ်ဆေးခြင်းအတွက် private key ကိုအသုံးပြု၍ RS256 JWT များကို ထုတ်ပေးသည်။

## Vonage အတွက် သီးသန့်မှတ်စုများ

- **NCCO vs TwiML**: Vonage သည် XML မှတ်သားမှုအစား JSON ပုံစံဖြင့် NCCO (Nexmo Call Control Objects) ကိုအသုံးပြုသည်။ Llamenos adapter သည် မှန်ကန်သောပုံစံကို အလိုအလျောက် ထုတ်ပေးသည်။
- **Answer URL ပုံစံ**: Vonage သည် answer URL မှ XML မဟုတ်ဘဲ JSON (NCCO) ကို ပြန်ပို့ရန် မျှော်လင့်သည်။ ၎င်းကို adapter မှ ကိုင်တွယ်သည်။
- **Event URL**: Vonage သည် ခေါ်ဆိုမှုဖြစ်စဉ်များ (မြည်ခြင်း၊ ဖြေကြားခြင်း၊ ပြီးဆုံးခြင်း) ကို JSON POST တောင်းဆိုမှုများအဖြစ် event URL သို့ ပေးပို့သည်။
- **Private key လုံခြုံရေး**: private key ကို ကုဒ်ဝှက်သိမ်းဆည်းထားသည်။ ၎င်းသည် ဆာဗာမှ ဘယ်တော့မှ မထွက်ခွာပါ -- သက်တမ်းတို JWT တိုကင်များထုတ်ပေးရန်အတွက်သာ အသုံးပြုသည်။

## ပြဿနာဖြေရှင်းခြင်း

- **"Application not found"**: Application ID အတိအကျတူညီကြောင်း စစ်ဆေးပါ။ Vonage Dashboard ရှိ **Applications** အောက်တွင် ၎င်းကိုရှာနိုင်သည်။
- **အဝင်ခေါ်ဆိုမှုများမရှိခြင်း**: ဖုန်းနံပါတ်သည် မှန်ကန်သော Application နှင့် ချိတ်ဆက်ထားကြောင်း သေချာပါစေ (အဆင့် 4)။
- **Private key အမှားများ**: `-----BEGIN PRIVATE KEY-----` နှင့် `-----END PRIVATE KEY-----` လိုင်းများအပါအဝင် PEM အကြောင်းအရာအပြည့်အစုံကို ကူးထည့်ပါ။
- **နိုင်ငံတကာနံပါတ်ပုံစံချခြင်း**: Vonage သည် E.164 ပုံစံ လိုအပ်သည်။ `+` နှင့် နိုင်ငံကုဒ်ကို ထည့်သွင်းပါ။
