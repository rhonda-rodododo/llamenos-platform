Llamenos သည် ၎င်း၏ **TelephonyAdapter** အင်တာဖေ့စ်မှတစ်ဆင့် တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူများစွာကို ပံ့ပိုးထားပါသည်။ သင်သည် အက်ပလီကေးရှင်းကုဒ်ကို မပြောင်းလဲဘဲ အက်ဒ်မင်ဆက်တင်များမှ အချိန်မရွေး ဝန်ဆောင်မှုပေးသူကို ပြောင်းလဲနိုင်ပါသည်။

|---|---|---|---|---|---|

## SIP တံတား

ကိုယ်တိုင်လက်ခံသော ဝန်ဆောင်မှုပေးသူများ (Asterisk, FreeSWITCH, Kamailio) ကို `sip-bridge` ဝန်ဆောင်မှုမှတစ်ဆင့် ဝင်ရောက်အသုံးပြုသည်။ နောက်ခံကို ရွေးချယ်ရန် `PBX_TYPE` ပတ်ဝန်းကျင်ပြောင်းကိန်းကို သတ်မှတ်ပါ:

```env
PBX_TYPE=asterisk      # Asterisk ARI
PBX_TYPE=freeswitch    # FreeSWITCH ESL
PBX_TYPE=kamailio      # Kamailio
```

## သတ်မှတ်နည်း

1. အက်ဒ်မင်ဘေးဘားရှိ **ဆက်တင်များ** သို့ သွားပါ
2. **တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူ** ကဏ္ဍကို ဖွင့်ပါ
3. သင့်ဝန်ဆောင်မှုပေးသူကို dropdown မှ ရွေးချယ်ပါ
4. လိုအပ်သော အထောက်အထားများကို ထည့်ပါ
5. သင့်ဟော့ပ်လိုင်းဖုန်းနံပါတ်ကို E.164 ပုံစံဖြင့် သတ်မှတ်ပါ (ဥပမာ `+15551234567`)
6. **သိမ်းရန်** ကိုနှိပ်ပါ
7. သင့်ဝန်ဆောင်မှုပေးသူ၏ ကွန်ဆိုးလ်တွင် webhook များကို သတ်မှတ်ပါ
