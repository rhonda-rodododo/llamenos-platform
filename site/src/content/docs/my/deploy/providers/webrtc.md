---

WebRTC (Web Real-Time Communication) သည် စေတနာ့ဝန်ထမ်းများအား ဖုန်းမလိုအပ်ဘဲ ၎င်းတို့၏ဘရောက်ဆာတွင် တိုက်ရိုက်ဟော့ပ်လိုင်းခေါ်ဆိုမှုများကို ဖြေကြားနိုင်စေသည်။ ၎င်းသည် ၎င်းတို့၏ဖုန်းနံပါတ်ကို မျှဝေလိုခြင်းမရှိသော သို့မဟုတ် ကွန်ပျူတာမှအလုပ်လုပ်သော စေတနာ့ဝန်ထမ်းများအတွက် အသုံးဝင်သည်။

## ၎င်းအလုပ်လုပ်ပုံ

1. အက်ဒ်မင်က တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူဆက်တင်များတွင် WebRTC ကိုဖွင့်သည်
2. စေတနာ့ဝန်ထမ်းများက ၎င်းတို့၏ပရိုဖိုင်တွင် ခေါ်ဆိုမှုဦးစားပေးကို "Browser" သို့ သတ်မှတ်သည်
3. ခေါ်ဆိုမှုတစ်ခုရောက်ရှိသောအခါ၊ Llamenos အက်ပ်သည် အကြောင်းကြားချက်တစ်ခုဖြင့် ဘရောက်ဆာတွင် မြည်သည်
4. စေတနာ့ဝန်ထမ်းက "Answer" ကိုနှိပ်ပြီး ခေါ်ဆိုမှုသည် ၎င်းတို့၏မိုက်ခရိုဖုန်းကိုအသုံးပြု၍ ဘရောက်ဆာမှတစ်ဆင့် ချိတ်ဆက်သည်

ခေါ်ဆိုမှုအသံသည် တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူမှ WebRTC ချိတ်ဆက်မှုမှတစ်ဆင့် စေတနာ့ဝန်ထမ်း၏ဘရောက်ဆာသို့ လမ်းကြောင်းပြောင်းပေးသည်။ ခေါ်ဆိုမှုအရည်အသွေးသည် စေတနာ့ဝန်ထမ်း၏ အင်တာနက်ချိတ်ဆက်မှုအပေါ် မူတည်သည်။

## ကြိုတင်လိုအပ်ချက်များ

### အက်ဒ်မင်သတ်မှတ်မှု

- WebRTC ဖွင့်ထားသော ပံ့ပိုးထားသည့် တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူ (Twilio, SignalWire, Vonage, သို့မဟုတ် Plivo)
- ဝန်ဆောင်မှုပေးသူအလိုက် WebRTC အထောက်အထားများ သတ်မှတ်ထားရန် (ဝန်ဆောင်မှုပေးသူ သတ်မှတ်လမ်းညွှန်များကိုကြည့်ပါ)
- **ဆက်တင်များ** > **တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူ** တွင် WebRTC ဖွင့်ထားရန်

### စေတနာ့ဝန်ထမ်း လိုအပ်ချက်များ

- ခေတ်မီဘရောက်ဆာ (Chrome, Firefox, Edge, သို့မဟုတ် Safari 14.1+)
- အလုပ်လုပ်သော မိုက်ခရိုဖုန်းတစ်ခု
- တည်ငြိမ်သောအင်တာနက်ချိတ်ဆက်မှု (အနည်းဆုံး 100 kbps အပေါ်/အောက်)
- ဘရောက်ဆာ အကြောင်းကြားချက်ခွင့်ပြုချက်များ ပေးထားရန်

## ဝန်ဆောင်မှုပေးသူအလိုက် သတ်မှတ်မှု

တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူတစ်ဦးချင်းစီသည် WebRTC အတွက် မတူညီသော အထောက်အထားများ လိုအပ်သည်:

### Twilio / SignalWire

1. ဝန်ဆောင်မှုပေးသူ၏ ကွန်ဆိုးလ်တွင် **API Key** တစ်ခုဖန်တီးပါ
2. Voice URL ကို `https://your-domain.com/api/telephony/webrtc-incoming` သို့ သတ်မှတ်ထားသော **TwiML/LaML Application** တစ်ခုဖန်တီးပါ
3. Llamenos တွင် API Key SID၊ API Key Secret နှင့် Application SID တို့ကို ထည့်သွင်းပါ

### Vonage

1. သင့် Vonage Application တွင် WebRTC စွမ်းဆောင်ရည် ပါရှိပြီးသားဖြစ်သည်
2. Llamenos တွင် သင့် Application ၏ **private key** (PEM ပုံစံ) ကို ကူးထည့်ပါ
3. Application ID ကို ကနဦးသတ်မှတ်မှုမှ ကြိုတင်သတ်မှတ်ပြီးဖြစ်သည်

### Plivo

1. Plivo ကွန်ဆိုးလ်တွင် **Voice** > **Endpoints** အောက်ရှိ **Endpoint** တစ်ခုဖန်တီးပါ
2. WebRTC သည် သင့်လက်ရှိ Auth ID နှင့် Auth Token ကိုအသုံးပြုသည်
3. Llamenos တွင် WebRTC ကိုဖွင့်ပါ -- နောက်ထပ်အထောက်အထားများ မလိုအပ်ပါ

### Asterisk

Asterisk WebRTC သည် WebSocket သယ်ယူပို့ဆောင်ရေးဖြင့် SIP.js ဖွဲ့စည်းမှု လိုအပ်သည်။ ၎င်းသည် ကလောက်ဝန်ဆောင်မှုပေးသူများထက် ပိုမိုပါဝင်ပတ်သက်သည်:

1. Asterisk ၏ `http.conf` တွင် WebSocket သယ်ယူပို့ဆောင်ရေးကို ဖွင့်ပါ
2. DTLS-SRTP ဖြင့် WebRTC ကလိုင်းယင့်များအတွက် PJSIP endpoints များဖန်တီးပါ
3. Asterisk ကိုရွေးချယ်သောအခါ Llamenos သည် SIP.js ကလိုင်းယင့်ကို အလိုအလျောက် သတ်မှတ်ပေးသည်

အသေးစိတ်အတွက် [Asterisk သတ်မှတ်လမ်းညွှန်](/docs/deploy/providers/asterisk) ကိုကြည့်ပါ။

## စေတနာ့ဝန်ထမ်း ခေါ်ဆိုမှုဦးစားပေးသတ်မှတ်ခြင်း

စေတနာ့ဝန်ထမ်းများသည် အက်ပ်တွင် ၎င်းတို့၏ ခေါ်ဆိုမှုဦးစားပေးကို သတ်မှတ်နိုင်သည်:

1. Llamenos သို့ ဝင်ရောက်ပါ
2. **ဆက်တင်များ** (ဂီယာအိုင်ကွန်) သို့ သွားပါ
3. **ခေါ်ဆိုမှုဦးစားပေးများ** အောက်တွင် **Phone** အစား **Browser** ကိုရွေးချယ်ပါ
4. တောင်းဆိုသောအခါ မိုက်ခရိုဖုန်းနှင့် အကြောင်းကြားချက်ခွင့်ပြုချက်များကို ပေးပါ
5. သင့်အလုပ်ချိန်အတွင်း Llamenos တက်ဘ်ကို ဖွင့်ထားပါ

ခေါ်ဆိုမှုတစ်ခုရောက်ရှိသောအခါ၊ ဘရောက်ဆာအကြောင်းကြားချက်တစ်ခုနှင့် အက်ပ်အတွင်းမြည်သောညွှန်ပြချက်တစ်ခုကို သင်တွေ့ရမည်ဖြစ်သည်။ ချိတ်ဆက်ရန် **Answer** ကိုနှိပ်ပါ။

## ဘရောက်ဆာ လိုက်ဖက်မှု

| ဘရောက်ဆာ | Desktop | Mobile | မှတ်ချက်များ |
|---|---|---|---|
| Chrome | ရှိသည် | ရှိသည် | အကြံပြုထား |
| Firefox | ရှိသည် | ရှိသည် | အပြည့်အဝပံ့ပိုးမှု |
| Edge | ရှိသည် | ရှိသည် | Chromium-based, အပြည့်အဝပံ့ပိုးမှု |
| Safari | ရှိသည် (14.1+) | ရှိသည် (14.1+) | အသံစတင်ရန် အသုံးပြုသူအပြန်အလှန်တုံ့ပြန်မှု လိုအပ် |
| Brave | ရှိသည် | အကန့်အသတ် | မိုက်ခရိုဖုန်းအတွက် shields ကိုပိတ်ရန် လိုအပ်နိုင် |

## အသံအရည်အသွေး အကြံပြုချက်များ

- ပဲ့တင်ထပ်ခြင်းကိုကာကွယ်ရန် နားကြပ် သို့မဟုတ် earbuds ကိုသုံးပါ
- မိုက်ခရိုဖုန်းကိုအသုံးပြုသော အခြားအက်ပလီကေးရှင်းများကို ပိတ်ပါ
- တတ်နိုင်ပါက ကြိုးတပ်အင်တာနက်ချိတ်ဆက်မှုကိုသုံးပါ
- WebRTC ကိုအနှောင့်အယှက်ဖြစ်စေနိုင်သော ဘရောက်ဆာ extension များကို ပိတ်ပါ (VPN extension များ၊ WebRTC ပေါက်ကြားမှုကာကွယ်ရေးပါသော ad blocker များ)

## ပြဿနာဖြေရှင်းခြင်း

### အသံမရှိခြင်း

- **မိုက်ခရိုဖုန်းခွင့်ပြုချက်ကိုစစ်ဆေးပါ**: လိပ်စာဘားရှိ သော့အိုင်ကွန်ကိုနှိပ်ပြီး မိုက်ခရိုဖုန်းဝင်ရောက်ခွင့်ကို "Allow" ဖြစ်ကြောင်း သေချာပါစေ
- **မိုက်ခရိုဖုန်းကိုစမ်းသပ်ပါ**: သင့်ဘရောက်ဆာ၏ built-in အသံစမ်းသပ်မှု သို့မဟုတ် [webcamtest.com](https://webcamtest.com) ကဲ့သို့သော ဆိုဒ်ကိုသုံးပါ
- **အသံထွက်ပေါက်ကိုစစ်ဆေးပါ**: သင့်စပီကာများ သို့မဟုတ် နားကြပ်ကို ထွက်ပေါက်စက်ပစ္စည်းအဖြစ် ရွေးချယ်ထားကြောင်း သေချာပါစေ

### ဘရောက်ဆာတွင် ခေါ်ဆိုမှုများမမြည်ခြင်း

- **အကြောင်းကြားချက်များပိတ်ဆို့ခံထားရ**: Llamenos ဆိုက်အတွက် ဘရောက်ဆာအကြောင်းကြားချက်များဖွင့်ထားကြောင်း စစ်ဆေးပါ
- **တက်ဘ်အလုပ်မလုပ်ခြင်း**: Llamenos တက်ဘ်သည် ဖွင့်ထားရမည် (နောက်ခံတွင်ရှိနိုင်သော်လည်း တက်ဘ်တည်ရှိရမည်)
- **ခေါ်ဆိုမှုဦးစားပေး**: ဆက်တင်များတွင် သင့်ခေါ်ဆိုမှုဦးစားပေးကို "Browser" သို့ သတ်မှတ်ထားကြောင်း စစ်ဆေးပါ
- **WebRTC မသတ်မှတ်ထားခြင်း**: WebRTC ဖွင့်ထားပြီး အထောက်အထားများသတ်မှတ်ထားကြောင်း အတည်ပြုရန် သင့်အက်ဒ်မင်ကိုမေးပါ

### Firewall နှင့် NAT ပြဿနာများ

WebRTC သည် firewall များနှင့် NAT ကိုဖြတ်ကျော်ရန် STUN/TURN ဆာဗာများကိုအသုံးပြုသည်။ ခေါ်ဆိုမှုများချိတ်ဆက်သော်လည်း အသံမကြားပါက:

- **ကော်ပိုရိတ် Firewall များ**: အချို့ firewall များသည် စံမဟုတ်သောဆိပ်ကမ်းများပေါ်ရှိ UDP အသွားအလာကို ပိတ်ဆို့သည်။ သင့် IT အဖွဲ့အား UDP ဆိပ်ကမ်း 3478 နှင့် 10000-60000 ကိုခွင့်ပြုရန်ပြောပါ
- **Symmetric NAT**: အချို့ router များသည် တိုက်ရိုက် peer ချိတ်ဆက်မှုများကိုတားဆီးနိုင်သော symmetric NAT ကိုအသုံးပြုသည်။ တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူ၏ TURN ဆာဗာများသည် ၎င်းကို အလိုအလျောက်ကိုင်တွယ်သင့်သည်
- **VPN အနှောင့်အယှက်**: VPN များသည် WebRTC ချိတ်ဆက်မှုများကို အနှောင့်အယှက်ဖြစ်စေနိုင်သည်။ အလုပ်ချိန်များအတွင်း သင့် VPN ကို ချိတ်ဆက်မှုဖြုတ်ကြည့်ပါ

### ပဲ့တင်ထပ်ခြင်း သို့မဟုတ် တုံ့ပြန်သံများ

- စပီကာများအစား နားကြပ်ကိုသုံးပါ
- သင့် OS အသံဆက်တင်များတွင် မိုက်ခရိုဖုန်းအာရုံခံနိုင်မှုကို လျှော့ချပါ
- သင့်ဘရောက်ဆာတွင် echo ပယ်ဖျက်ခြင်းကိုဖွင့်ပါ (များသောအားဖြင့် ပုံမှန်အားဖြင့်ဖွင့်ထားသည်)
- မာကျောသော၊ ရောင်ပြန်ဟပ်သော မျက်နှာပြင်များနှင့် ဝေးဝေးနေပါ
