---

Llamenos ရှိ SMS မက်ဆေ့ချ်ပို့ခြင်းသည် သင့်လက်ရှိအသံတယ်လီဖုန်းဝန်ဆောင်မှုပေးသူ၏ အထောက်အထားများကို ပြန်လည်အသုံးပြုသည်။ သီးခြား SMS ဝန်ဆောင်မှုမလိုအပ်ပါ — သင်သည် Twilio၊ SignalWire၊ Vonage သို့မဟုတ် Plivo ကို အသံအတွက် ကြိုတင်သတ်မှတ်ထားပြီးပါက၊ SMS သည် တူညီသောအကောင့်ဖြင့် အလုပ်လုပ်ပါသည်။

## ပံ့ပိုးထားသော ဝန်ဆောင်မှုပေးသူများ

| ဝန်ဆောင်မှုပေးသူ | SMS ပံ့ပိုးမှု | မှတ်ချက်များ |
|----------|------------|-------|
| **Twilio** | ရှိသည် | Twilio Messaging API မှတစ်ဆင့် လမ်းကြောင်းနှစ်ဖက်စလုံး SMS အပြည့်အစုံ |
| **SignalWire** | ရှိသည် | Twilio API နှင့် ကိုက်ညီသည် — တူညီသောအင်တာဖေ့စ် |
| **Vonage** | ရှိသည် | Vonage REST API မှတစ်ဆင့် SMS |
| **Plivo** | ရှိသည် | Plivo Message API မှတစ်ဆင့် SMS |
| **Asterisk** | မရှိ | Asterisk သည် မူရင်း SMS ကို မပံ့ပိုးပါ |

## 1. အက်ဒ်မင်ဆက်တင်များတွင် SMS ကိုဖွင့်ပါ

**အက်ဒ်မင်ဆက်တင်များ > မက်ဆေ့ချ်ချန်နယ်များ** သို့ သွားပါ (သို့မဟုတ် ပထမဆုံးဝင်ရောက်ချိန်တွင် setup wizard ကိုသုံးပါ) ပြီး **SMS** ကိုဖွင့်ပါ။

SMS ဆက်တင်များကို သတ်မှတ်ပါ:
- **အလိုအလျောက်တုံ့ပြန်စာ** — ပထမဆုံးအကြိမ်ဆက်သွယ်သူများထံ ပေးပို့ရန် ချန်လှပ်နိုင်သော ကြိုဆိုစာ
- **အလုပ်ချိန်ပြင်ပအချိန်တုံ့ပြန်စာ** — အလုပ်ချိန်ပြင်ပတွင် ပေးပို့ရန် ချန်လှပ်နိုင်သော စာ

## 2. Webhook ကို သတ်မှတ်ပါ

သင့်တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူ၏ SMS webhook ကို သင့်ဆာဗာသို့ ညွှန်ပြပါ:

```
POST https://your-domain.com/api/messaging/sms/webhook
```

### Twilio / SignalWire

1. သင့် Twilio ကွန်ဆိုးလ် > Phone Numbers > Active Numbers သို့ သွားပါ
2. သင့်ဖုန်းနံပါတ်ကိုရွေးချယ်ပါ
3. **Messaging** အောက်တွင်၊ "A message comes in" အတွက် webhook URL ကို အထက်ပါ URL သို့ သတ်မှတ်ပါ
4. HTTP method ကို **POST** သို့ သတ်မှတ်ပါ

### Vonage

1. Vonage API Dashboard > Applications သို့ သွားပါ
2. သင့် application ကိုရွေးချယ်ပါ
3. **Messages** အောက်တွင်၊ Inbound URL ကို အထက်ပါ webhook URL သို့ သတ်မှတ်ပါ

### Plivo

1. Plivo ကွန်ဆိုးလ် > Messaging > Applications သို့ သွားပါ
2. မက်ဆေ့ချ် application တစ်ခုကို ဖန်တီးပါ သို့မဟုတ် တည်းဖြတ်ပါ
3. Message URL ကို အထက်ပါ webhook URL သို့ သတ်မှတ်ပါ
4. Application ကို သင့်ဖုန်းနံပါတ်သို့ သတ်မှတ်ပါ

## 3. စမ်းသပ်ပါ

သင့်ဟော့ပ်လိုင်းဖုန်းနံပါတ်သို့ SMS တစ်စောင် ပို့ပါ။ အက်ဒ်မင်အကန့်ရှိ **စကားပြောဆိုမှုများ** တက်ဘ်တွင် စကားပြောဆိုမှုကို သင်တွေ့ရမည်ဖြစ်သည်။

## ၎င်းအလုပ်လုပ်ပုံ

1. SMS တစ်စောင်သည် သင့်ဝန်ဆောင်မှုပေးသူထံ ရောက်ရှိပြီး သင့်ဆာဗာသို့ webhook တစ်ခု ပေးပို့သည်
2. ဆာဗာသည် webhook လက်မှတ် (ဝန်ဆောင်မှုပေးသူအလိုက် HMAC) ကို အတည်ပြုသည်
3. မက်ဆေ့ချ်ကို ခွဲခြမ်းစိတ်ဖြာပြီး ConversationService တွင် သိမ်းဆည်းသည်
4. အလုပ်ချိန်အတွင်း စေတနာ့ဝန်ထမ်းများအား WebSocket relay ဖြစ်ရပ်များမှတစ်ဆင့် အကြောင်းကြားသည်
5. စေတနာ့ဝန်ထမ်းများသည် စကားပြောဆိုမှုများတက်ဘ်မှ ပြန်ကြားသည် — တုံ့ပြန်မှုများကို သင့်ဝန်ဆောင်မှုပေးသူ၏ SMS API မှတစ်ဆင့် ပြန်ပို့သည်

## လုံခြုံရေးမှတ်စုများ

- SMS မက်ဆေ့ချ်များသည် ကယ်ရီယာကွန်ရက်ကို ရိုးရိုးစာသားဖြင့် ဖြတ်သန်းသည် — သင့်ဝန်ဆောင်မှုပေးသူနှင့် ကယ်ရီယာများက ၎င်းတို့ကို ဖတ်နိုင်သည်
- အဝင်မက်ဆေ့ချ်များကို လက်ခံရရှိချိန်တွင် ကုဒ်ဝှက်ပြီး ဒေတာဘေ့စ်တွင် သိမ်းဆည်းသည်
- ပို့သူဖုန်းနံပါတ်များကို သိမ်းဆည်းခြင်းမပြုမီ hash လုပ်ထားသည် (ကိုယ်ရေးလုံခြုံမှု)
- Webhook လက်မှတ်များကို ဝန်ဆောင်မှုပေးသူအလိုက် အတည်ပြုသည် (Twilio အတွက် HMAC-SHA1 စသည်)
