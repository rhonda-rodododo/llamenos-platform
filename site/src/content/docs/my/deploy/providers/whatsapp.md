---

Llamenos သည် Meta Cloud API (Graph API v21.0) မှတစ်ဆင့် WhatsApp Business မက်ဆေ့ချ်ပို့ခြင်းကို ပံ့ပိုးထားသည်။ WhatsApp သည် စာသား၊ ပုံများ၊ စာရွက်စာတမ်းများ၊ အသံနှင့် အပြန်အလှန်တုံ့ပြန်နိုင်သော မက်ဆေ့ချ်များအတွက် ပံ့ပိုးမှုဖြင့် ကြွယ်ဝသော မက်ဆေ့ချ်ပို့ခြင်းကို ပေးဆောင်သည်။

## ကြိုတင်လိုအပ်ချက်များ

- [Meta Business အကောင့်](https://business.facebook.com) တစ်ခု
- WhatsApp Business API ဖုန်းနံပါတ်တစ်ခု
- WhatsApp ထုတ်ကုန်ဖွင့်ထားသော Meta developer အက်ပ်တစ်ခု

## ပေါင်းစည်းမှုမုဒ်များ

Llamenos သည် WhatsApp ပေါင်းစည်းမှုမုဒ် နှစ်မျိုးကို ပံ့ပိုးထားသည်:

### Meta တိုက်ရိုက် (အကြံပြုထား)

Meta Cloud API သို့ တိုက်ရိုက်ချိတ်ဆက်ပါ။ အပြည့်အဝထိန်းချုပ်မှုနှင့် အင်္ဂါရပ်အားလုံးကို ပေးဆောင်သည်။

**လိုအပ်သော အထောက်အထားများ:**
- **Phone Number ID** — သင့် WhatsApp Business ဖုန်းနံပါတ် ID
- **Business Account ID** — သင့် Meta Business အကောင့် ID
- **Access Token** — သက်တမ်းရှည် Meta API ဝင်ရောက်ခွင့်တိုကင်
- **Verify Token** — webhook အတည်ပြုခြင်းအတွက် သင်ရွေးချယ်သော စိတ်ကြိုက်စာကြောင်း
- **App Secret** — သင့် Meta အက်ပ်လျှို့ဝှက်ချက် (webhook လက်မှတ်အတည်ပြုခြင်းအတွက်)

### Twilio မုဒ်

သင်သည် အသံအတွက် Twilio ကို သုံးနှင့်ပြီးသားဖြစ်ပါက၊ သင်သည် WhatsApp ကို သင့် Twilio အကောင့်မှတစ်ဆင့် လမ်းကြောင်းပြောင်းနိုင်သည်။ သတ်မှတ်ရန် ပိုမိုရိုးရှင်းသော်လည်း အချို့အင်္ဂါရပ်များ အကန့်အသတ်ရှိနိုင်သည်။

**လိုအပ်သော အထောက်အထားများ:**
- သင့်လက်ရှိ Twilio Account SID, Auth Token နှင့် Twilio-ချိတ်ဆက်ထားသော WhatsApp ပို့သူ

## 1. Meta အက်ပ်တစ်ခုဖန်တီးပါ

1. [developers.facebook.com](https://developers.facebook.com) သို့ သွားပါ
2. အက်ပ်အသစ်တစ်ခုဖန်တီးပါ (အမျိုးအစား: Business)
3. **WhatsApp** ထုတ်ကုန်ကို ထည့်ပါ
4. WhatsApp > Getting Started တွင်၊ သင့် **Phone Number ID** နှင့် **Business Account ID** တို့ကို မှတ်သားပါ
5. အမြဲတမ်းဝင်ရောက်ခွင့်တိုကင်တစ်ခုကို ထုတ်ပေးပါ (Settings > Access Tokens)

## 2. Webhook ကို သတ်မှတ်ပါ

Meta developer dashboard တွင်:

1. WhatsApp > Configuration > Webhook သို့ သွားပါ
2. Callback URL ကို အောက်ပါအတိုင်း သတ်မှတ်ပါ:
   ```
   https://your-domain.com/api/messaging/whatsapp/webhook
   ```
3. Verify Token ကို သင်သည် Llamenos အက်ဒ်မင်ဆက်တင်များတွင် ထည့်သွင်းမည့် စာကြောင်းအတိုင်း သတ်မှတ်ပါ
4. `messages` webhook အကွက်အတွက် စာရင်းသွင်းပါ

Meta သည် webhook ကိုအတည်ပြုရန် GET တောင်းဆိုမှုတစ်ခုကို ပေးပို့လိမ့်မည်။ verify token နှင့်ကိုက်ညီပါက သင့်ဆာဗာသည် challenge ဖြင့် တုံ့ပြန်လိမ့်မည်။

## 3. အက်ဒ်မင်ဆက်တင်များတွင် WhatsApp ကိုဖွင့်ပါ

**အက်ဒ်မင်ဆက်တင်များ > မက်ဆေ့ချ်ချန်နယ်များ** သို့ သွားပါ (သို့မဟုတ် setup wizard ကိုသုံးပါ) ပြီး **WhatsApp** ကိုဖွင့်ပါ။

**Meta တိုက်ရိုက်** သို့မဟုတ် **Twilio** မုဒ်ကိုရွေးချယ်ပြီး လိုအပ်သော အထောက်အထားများကို ထည့်သွင်းပါ။

ချန်လှပ်နိုင်သော ဆက်တင်များကို သတ်မှတ်ပါ:
- **အလိုအလျောက်တုံ့ပြန်စာ** — ပထမဆုံးအကြိမ်ဆက်သွယ်သူများထံ ပေးပို့သည်
- **အလုပ်ချိန်ပြင်ပအချိန်တုံ့ပြန်စာ** — အလုပ်ချိန်ပြင်ပတွင် ပေးပို့သည်

## 4. စမ်းသပ်ပါ

သင့် Business ဖုန်းနံပါတ်သို့ WhatsApp မက်ဆေ့ချ်တစ်စောင် ပို့ပါ။ စကားပြောဆိုမှုသည် **စကားပြောဆိုမှုများ** တက်ဘ်တွင် ပေါ်လာသင့်ပါသည်။

## ၂၄ နာရီ မက်ဆေ့ချ်ပို့သည့်ပြတင်းပေါက်

WhatsApp သည် ၂၄ နာရီ မက်ဆေ့ချ်ပို့သည့်ပြတင်းပေါက်ကို ကျင့်သုံးသည်:
- သင်သည် အသုံးပြုသူ၏ နောက်ဆုံးမက်ဆေ့ချ်ပြီးနောက် ၂၄ နာရီအတွင်း ပြန်ကြားနိုင်သည်
- ၂၄ နာရီကျော်ပါက၊ စကားပြောဆိုမှုကို ပြန်လည်စတင်ရန် အတည်ပြုထားသော **template message** ကို သင်အသုံးပြုရမည်
- Llamenos သည် ၎င်းကို အလိုအလျောက် ကိုင်တွယ်သည် — ပြတင်းပေါက်သက်တမ်းကုန်သွားပါက စကားပြောဆိုမှုကို ပြန်လည်စတင်ရန် template message ကို ပေးပို့သည်

## မီဒီယာပံ့ပိုးမှု

WhatsApp သည် ကြွယ်ဝသော မီဒီယာမက်ဆေ့ချ်များကို ပံ့ပိုးသည်:
- **ပုံများ** (JPEG, PNG)
- **စာရွက်စာတမ်းများ** (PDF, Word, စသည်)
- **အသံ** (MP3, OGG)
- **ဗီဒီယို** (MP4)
- **တည်နေရာ** မျှဝေခြင်း
- **အပြန်အလှန်တုံ့ပြန်** ခလုတ်များနှင့် စာရင်းမက်ဆေ့ချ်များ

မီဒီယာပူးတွဲပါဖိုင်များသည် စကားပြောဆိုမှုမြင်ကွင်းတွင် အတန်းလိုက်ပေါ်လာသည်။

## လုံခြုံရေးမှတ်စုများ

- WhatsApp သည် အသုံးပြုသူနှင့် Meta ၏ အခြေခံအဆောက်အအုံကြားတွင် အဆုံးမှအဆုံးကုဒ်ဝှက်ခြင်းကို အသုံးပြုသည်
- Meta သည် ၎င်းတို့၏ဆာဗာများပေါ်ရှိ မက်ဆေ့ချ်အကြောင်းအရာကို နည်းပညာအရ ဝင်ရောက်ကြည့်ရှုနိုင်သည်
- မက်ဆေ့ချ်များကို လက်ခံရရှိချိန်တွင် ကုဒ်ဝှက်ပြီး ဒေတာဘေ့စ်တွင် သိမ်းဆည်းသည်
- Webhook လက်မှတ်များကို သင့် app secret ဖြင့် HMAC-SHA256 ကိုအသုံးပြု၍ အတည်ပြုသည်
- အမြင့်ဆုံး ကိုယ်ရေးလုံခြုံမှုအတွက် WhatsApp အစား Signal ကိုသုံးရန် စဉ်းစားပါ
