---

Plivo သည် ဘတ်ဂျက်အဆင်ပြေသော ကလောက်တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူတစ်ခုဖြစ်ပြီး ရှင်းလင်းသော API တစ်ခုပါရှိသည်။ ၎င်းသည် TwiML နှင့်ဆင်တူသော XML-based ခေါ်ဆိုမှုထိန်းချုပ်မှုကို အသုံးပြုကာ Llamenos နှင့် ချောမွေ့စွာ ပေါင်းစည်းနိုင်စေသည်။

## ကြိုတင်လိုအပ်ချက်များ

- [Plivo အကောင့်](https://console.plivo.com/accounts/register/) (အစမ်းသုံးခရက်ဒစ်ရရှိနိုင်)
- သင့် Llamenos အင်စတန်းကို အများသုံး URL တစ်ခုမှတစ်ဆင့် ဝင်ရောက်နိုင်ရန် ဖြန့်ကျက်ထားရန်

## 1. Plivo အကောင့်ဖွင့်ပါ

[console.plivo.com](https://console.plivo.com/accounts/register/) တွင် စာရင်းသွင်းပါ။ အတည်ပြုပြီးနောက်၊ သင့် **Auth ID** နှင့် **Auth Token** တို့ကို dashboard ပင်မစာမျက်နှာတွင် တွေ့ရှိနိုင်ပါသည်။

## 2. ဖုန်းနံပါတ်တစ်ခုဝယ်ပါ

1. Plivo ကွန်ဆိုးလ်တွင် **Phone Numbers** > **Buy Numbers** သို့ သွားပါ
2. သင့်နိုင်ငံကိုရွေးချယ်ပြီး အသံစွမ်းဆောင်ရည်ရှိသော နံပါတ်များကို ရှာဖွေပါ
3. နံပါတ်တစ်ခုကို ဝယ်ယူပါ

## 3. XML အပလီကေးရှင်းတစ်ခုဖန်တီးပါ

Plivo သည် ခေါ်ဆိုမှုများကို လမ်းကြောင်းပြောင်းရန် "XML Applications" ကိုအသုံးပြုသည်:

1. **Voice** > **XML Applications** သို့ သွားပါ
2. **Add New Application** ကိုနှိပ်ပါ
3. အောက်ပါတို့ကို သတ်မှတ်ပါ:
   - **Application Name**: Llamenos Hotline
   - **Answer URL**: `https://your-domain.com/api/telephony/incoming` (POST)
   - **Hangup URL**: `https://your-domain.com/api/telephony/status` (POST)
4. အပလီကေးရှင်းကို သိမ်းပါ

## 4. ဖုန်းနံပါတ်ကို ချိတ်ဆက်ပါ

1. **Phone Numbers** > **Your Numbers** သို့ သွားပါ
2. သင့်ဟော့ပ်လိုင်းနံပါတ်ကိုနှိပ်ပါ
3. **Voice** အောက်တွင်၊ အဆင့် 3 တွင် သင်ဖန်တီးထားသော XML Application ကိုရွေးချယ်ပါ
4. သိမ်းပါ

## 5. Llamenos တွင် သတ်မှတ်ပါ

1. အက်ဒ်မင်အဖြစ် ဝင်ရောက်ပါ
2. **ဆက်တင်များ** > **တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူ** သို့ သွားပါ
3. ဝန်ဆောင်မှုပေးသူ dropdown မှ **Plivo** ကိုရွေးချယ်ပါ
4. အောက်ပါတို့ကို ထည့်သွင်းပါ:
   - **Auth ID**: Plivo ကွန်ဆိုးလ် dashboard မှ
   - **Auth Token**: Plivo ကွန်ဆိုးလ် dashboard မှ
   - **Phone Number**: သင်ဝယ်ထားသော နံပါတ် (E.164 ပုံစံ)
5. **သိမ်းရန်** ကိုနှိပ်ပါ

## 6. သတ်မှတ်မှုကို စမ်းသပ်ပါ

သင့်ဟော့ပ်လိုင်းနံပါတ်ကို ခေါ်ဆိုပါ။ ဘာသာစကားရွေးချယ်မှုမီနူးကို သင်ကြားရမည်ဖြစ်ပြီး သာမန်ခေါ်ဆိုမှုလမ်းကြောင်းအတိုင်း လမ်းကြောင်းပြောင်းပေးမည်ဖြစ်သည်။

## WebRTC သတ်မှတ်ခြင်း (ချန်လှပ်နိုင်)

Plivo WebRTC သည် သင့်လက်ရှိအထောက်အထားများဖြင့် Browser SDK ကိုအသုံးပြုသည်:

1. Plivo ကွန်ဆိုးလ်တွင် **Voice** > **Endpoints** သို့ သွားပါ
2. endpoint အသစ်တစ်ခုဖန်တီးပါ (၎င်းသည် ဘရောက်ဆာဖုန်းအထောက်အထားအဖြစ် ဆောင်ရွက်သည်)
3. Llamenos တွင် **ဆက်တင်များ** > **တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူ** သို့ သွားပါ
4. **WebRTC ခေါ်ဆိုခြင်း** ကို ဖွင့်ပါ
5. **သိမ်းရန်** ကိုနှိပ်ပါ

Adapter သည် လုံခြုံသောဘရောက်ဆာအထောက်အထားစစ်ဆေးခြင်းအတွက် သင့် Auth ID နှင့် Auth Token မှ အချိန်ကန့်သတ် HMAC တိုကင်များကို ထုတ်ပေးသည်။

## Plivo အတွက် သီးသန့်မှတ်စုများ

- **XML vs TwiML**: Plivo သည် ခေါ်ဆိုမှုထိန်းချုပ်ရန်အတွက် ၎င်း၏ကိုယ်ပိုင် XML ပုံစံကိုအသုံးပြုပြီး ၎င်းသည် TwiML နှင့်ဆင်တူသော်လည်း တူညီမှုမရှိပါ။ Llamenos adapter သည် မှန်ကန်သော Plivo XML ကို အလိုအလျောက် ထုတ်ပေးသည်။
- **Answer URL vs Hangup URL**: Plivo သည် Twilio ကဲ့သို့ status callback တစ်ခုတည်းအစား ကနဦးခေါ်ဆိုမှုကိုင်တွယ်သူ (Answer URL) နှင့် ခေါ်ဆိုမှုအဆုံးသတ်ကိုင်တွယ်သူ (Hangup URL) တို့ကို သီးခြားခွဲထားသည်။
- **Rate limits**: Plivo တွင် အကောင့်အဆင့်အလိုက် ကွဲပြားသော API rate limits များရှိသည်။ ပမာဏများပြားသောဟော့ပ်လိုင်းများအတွက် ကန့်သတ်ချက်များတိုးရန် Plivo ပံ့ပိုးကူညီမှုကို ဆက်သွယ်ပါ။

## ပြဿနာဖြေရှင်းခြင်း

- **"Auth ID invalid"**: Auth ID သည် သင့်အီးမေးလ်လိပ်စာမဟုတ်ပါ။ Plivo ကွန်ဆိုးလ် dashboard ပင်မစာမျက်နှာတွင် ၎င်းကိုရှာပါ။
- **ခေါ်ဆိုမှုများလမ်းကြောင်းမပြောင်းခြင်း**: ဖုန်းနံပါတ်သည် မှန်ကန်သော XML Application နှင့် ချိတ်ဆက်ထားကြောင်း စစ်ဆေးပါ။
- **Answer URL အမှားများ**: Plivo သည် မှန်ကန်သော XML တုံ့ပြန်မှုများကို မျှော်လင့်သည်။ တုံ့ပြန်မှုအမှားများအတွက် သင့်ဆာဗာမှတ်တမ်းများကို စစ်ဆေးပါ။
- **အထွက်ခေါ်ဆိုမှုကန့်သတ်ချက်များ**: အစမ်းသုံးအကောင့်များတွင် အထွက်ခေါ်ဆိုမှုအတွက် ကန့်သတ်ချက်များရှိသည်။ ထုတ်လုပ်မှုအသုံးပြုရန်အတွက် အဆင့်မြှင့်ပါ။
