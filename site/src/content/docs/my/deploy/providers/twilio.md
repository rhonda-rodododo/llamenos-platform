---

Twilio သည် Llamenos အတွက် ပုံမှန်တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူဖြစ်ပြီး စတင်ရန် အလွယ်ကူဆုံးဖြစ်သည်။ ဤလမ်းညွှန်သည် အကောင့်ဖွင့်ခြင်း၊ ဖုန်းနံပါတ်သတ်မှတ်ခြင်းနှင့် webhook ပြင်ဆင်ခြင်းတို့ကို အဆင့်ဆင့် လမ်းညွှန်ပေးပါမည်။

## ကြိုတင်လိုအပ်ချက်များ

- [Twilio အကောင့်](https://www.twilio.com/try-twilio) (အခမဲ့အစမ်းသုံးသည် စမ်းသပ်ရန်အတွက် အလုပ်ဖြစ်သည်)
- သင့် Llamenos အင်စတန်းကို အများသုံး URL တစ်ခုမှတစ်ဆင့် ဝင်ရောက်နိုင်ရန် ဖြန့်ကျက်ထားရန်

## 1. Twilio အကောင့်ဖွင့်ပါ

[twilio.com/try-twilio](https://www.twilio.com/try-twilio) တွင် စာရင်းသွင်းပါ။ သင့်အီးမေးလ်နှင့် ဖုန်းနံပါတ်ကို အတည်ပြုပါ။ Twilio သည် စမ်းသပ်ရန်အတွက် အစမ်းသုံးခရက်ဒစ်ကို ပေးပါသည်။

## 2. ဖုန်းနံပါတ်တစ်ခုဝယ်ပါ

1. Twilio ကွန်ဆိုးလ်တွင် **Phone Numbers** > **Manage** > **Buy a number** သို့ သွားပါ
2. သင်လိုချင်သော ဧရိယာကုဒ်တွင် **Voice** စွမ်းဆောင်ရည်ရှိသော နံပါတ်တစ်ခုကို ရှာဖွေပါ
3. **Buy** ကိုနှိပ်ပြီး အတည်ပြုပါ

ဤနံပါတ်ကို သိမ်းထားပါ -- သင်သည် Llamenos အက်ဒ်မင်ဆက်တင်များတွင် ၎င်းကို ထည့်သွင်းရမည်ဖြစ်သည်။

## 3. သင့် Account SID နှင့် Auth Token ကိုရယူပါ

1. [Twilio Console dashboard](https://console.twilio.com) သို့ သွားပါ
2. ပင်မစာမျက်နှာတွင် သင့် **Account SID** နှင့် **Auth Token** ကိုရှာပါ
3. Auth Token ကို ပြသရန် မျက်လုံးအိုင်ကွန်ကိုနှိပ်ပါ

## 4. Webhook များကို သတ်မှတ်ပါ

Twilio ကွန်ဆိုးလ်တွင်၊ သင့်ဖုန်းနံပါတ်၏ ဖွဲ့စည်းမှုသို့ သွားပါ:

1. **Phone Numbers** > **Manage** > **Active Numbers** သို့ သွားပါ
2. သင့်ဟော့ပ်လိုင်းနံပါတ်ကိုနှိပ်ပါ
3. **Voice Configuration** အောက်တွင်၊ အောက်ပါတို့ကို သတ်မှတ်ပါ:
   - **A call comes in**: Webhook, `https://your-domain.com/api/telephony/incoming`, HTTP POST
   - **Call status changes**: `https://your-domain.com/api/telephony/status`, HTTP POST

`your-domain.com` ကို သင့်တကယ့် Llamenos ဖြန့်ကျက်မှု URL ဖြင့် အစားထိုးပါ။

## 5. Llamenos တွင် သတ်မှတ်ပါ

1. အက်ဒ်မင်အဖြစ် ဝင်ရောက်ပါ
2. **ဆက်တင်များ** > **တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူ** သို့ သွားပါ
3. ဝန်ဆောင်မှုပေးသူ dropdown မှ **Twilio** ကိုရွေးချယ်ပါ
4. အောက်ပါတို့ကို ထည့်သွင်းပါ:
   - **Account SID**: အဆင့် 3 မှ
   - **Auth Token**: အဆင့် 3 မှ
   - **Phone Number**: သင်ဝယ်ထားသော နံပါတ် (E.164 ပုံစံ၊ ဥပမာ `+15551234567`)
5. **သိမ်းရန်** ကိုနှိပ်ပါ

## 6. သတ်မှတ်မှုကို စမ်းသပ်ပါ

ဖုန်းတစ်လုံးမှ သင့်ဟော့ပ်လိုင်းနံပါတ်ကို ခေါ်ဆိုပါ။ ဘာသာစကားရွေးချယ်မှုမီနူးကို သင်ကြားရမည်ဖြစ်သည်။ သင့်တွင် အလုပ်ချိန်အတွင်း စေတနာ့ဝန်ထမ်းများရှိပါက၊ ခေါ်ဆိုမှုသည် ၎င်းတို့ထံ လက်ဆင့်ကမ်းသွားမည်ဖြစ်သည်။

## WebRTC သတ်မှတ်ခြင်း (ချန်လှပ်နိုင်)

စေတနာ့ဝန်ထမ်းများအား ၎င်းတို့၏ဖုန်းအစား ဘရောက်ဆာတွင် ခေါ်ဆိုမှုများကို ဖြေကြားနိုင်စေရန်:

### API Key တစ်ခုဖန်တီးပါ

1. Twilio ကွန်ဆိုးလ်တွင် **Account** > **API keys & tokens** သို့ သွားပါ
2. **Create API Key** ကိုနှိပ်ပါ
3. **Standard** သော့အမျိုးအစားကို ရွေးချယ်ပါ
4. **SID** နှင့် **Secret** တို့ကို သိမ်းပါ -- လျှို့ဝှက်ချက်ကို တစ်ကြိမ်သာ ပြသပါမည်

### TwiML အက်ပ်တစ်ခုဖန်တီးပါ

1. **Voice** > **Manage** > **TwiML Apps** သို့ သွားပါ
2. **Create new TwiML App** ကိုနှိပ်ပါ
3. **Voice Request URL** ကို `https://your-domain.com/api/telephony/webrtc-incoming` သို့ သတ်မှတ်ပါ
4. သိမ်းပြီး **App SID** ကို မှတ်သားပါ

### Llamenos တွင် ဖွင့်ပါ

1. **ဆက်တင်များ** > **တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူ** သို့ သွားပါ
2. **WebRTC ခေါ်ဆိုခြင်း** ကို ဖွင့်ပါ
3. အောက်ပါတို့ကို ထည့်သွင်းပါ:
   - **API Key SID**: သင်ဖန်တီးထားသော API key မှ
   - **API Key Secret**: သင်ဖန်တီးထားသော API key မှ
   - **TwiML App SID**: သင်ဖန်တီးထားသော TwiML App မှ
4. **သိမ်းရန်** ကိုနှိပ်ပါ

စေတနာ့ဝန်ထမ်းသတ်မှတ်ခြင်းနှင့် ပြဿနာဖြေရှင်းခြင်းအတွက် [WebRTC ဘရောက်ဆာခေါ်ဆိုခြင်း](/docs/deploy/providers/webrtc) ကို ကြည့်ပါ။

## ပြဿနာဖြေရှင်းခြင်း

- **ခေါ်ဆိုမှုများမရောက်ရှိခြင်း**: webhook URL မှန်ကန်ကြောင်းနှင့် သင့်ဆာဗာကို ဖြန့်ကျက်ထားကြောင်း စစ်ဆေးပါ။ Twilio ကွန်ဆိုးလ် အမှားမှတ်တမ်းများကို စစ်ဆေးပါ။
- **"Invalid webhook" အမှားများ**: webhook URL သည် HTTPS ကိုအသုံးပြုပြီး မှန်ကန်သော TwiML ကို ပြန်ပို့ကြောင်း သေချာပါစေ။
- **အစမ်းသုံးအကောင့် ကန့်သတ်ချက်များ**: အစမ်းသုံးအကောင့်များသည် အတည်ပြုထားသောနံပါတ်များကိုသာ ခေါ်ဆိုနိုင်သည်။ ထုတ်လုပ်မှုအသုံးပြုရန်အတွက် ပေးချေအကောင့်သို့ အဆင့်မြှင့်ပါ။
- **Webhook အတည်ပြုခြင်းမအောင်မြင်ခြင်း**: Llamenos ရှိ Auth Token သည် Twilio ကွန်ဆိုးလ်ရှိ Auth Token နှင့် တူညီကြောင်း သေချာပါစေ။
