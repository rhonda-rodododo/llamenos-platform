---

SignalWire သည် Twilio ၏ အဆင်ပြေသော API တစ်ခုပါရှိသည့် ကုန်ကျစရိတ်သက်သာသော အခြားရွေးချယ်မှုတစ်ခုဖြစ်သည်။ ၎င်းသည် LaML (TwiML နှင့် လိုက်ဖက်သော မှတ်သားမှုဘာသာစကား) ကိုအသုံးပြုသောကြောင့် Twilio နှင့် SignalWire အကြား ပြောင်းရွှေ့ရန် လွယ်ကူပါသည်။

## ကြိုတင်လိုအပ်ချက်များ

- [SignalWire အကောင့်](https://signalwire.com/signup) (အခမဲ့အစမ်းသုံးရရှိနိုင်ပါသည်)
- သင့် Llamenos အင်စတန်းကို အများသုံး URL တစ်ခုမှတစ်ဆင့် ဝင်ရောက်နိုင်ရန် ဖြန့်ကျက်ထားရန်

## 1. SignalWire အကောင့်ဖွင့်ပါ

[signalwire.com/signup](https://signalwire.com/signup) တွင် စာရင်းသွင်းပါ။ စာရင်းသွင်းစဉ်အတွင်း သင်သည် **Space name** တစ်ခုကို ရွေးချယ်ရမည်ဖြစ်သည် (ဥပမာ `myhotline`)။ သင့် Space URL သည် `myhotline.signalwire.com` ဖြစ်လိမ့်မည်။ ဤအမည်ကို မှတ်သားထားပါ -- သင်သည် ဖွဲ့စည်းမှုတွင် ၎င်းကို လိုအပ်မည်ဖြစ်သည်။

## 2. ဖုန်းနံပါတ်တစ်ခုဝယ်ပါ

1. သင့် SignalWire Dashboard တွင် **Phone Numbers** သို့ သွားပါ
2. **Buy a Phone Number** ကိုနှိပ်ပါ
3. အသံစွမ်းဆောင်ရည်ပါသော နံပါတ်တစ်ခုကို ရှာဖွေပါ
4. နံပါတ်ကို ဝယ်ယူပါ

## 3. သင့်အထောက်အထားများကိုရယူပါ

1. SignalWire Dashboard တွင် **API** သို့ သွားပါ
2. သင့် **Project ID** ကိုရှာပါ (၎င်းသည် Account SID အဖြစ် ဆောင်ရွက်သည်)
3. သင့်တွင် မရှိပါက **API Token** အသစ်တစ်ခုဖန်တီးပါ -- ၎င်းသည် Auth Token အဖြစ် ဆောင်ရွက်သည်

## 4. Webhook များကို သတ်မှတ်ပါ

1. Dashboard ရှိ **Phone Numbers** သို့ သွားပါ
2. သင့်ဟော့ပ်လိုင်းနံပါတ်ကိုနှိပ်ပါ
3. **Voice Settings** အောက်တွင်၊ အောက်ပါတို့ကို သတ်မှတ်ပါ:
   - **Handle calls using**: LaML Webhooks
   - **When a call comes in**: `https://your-domain.com/api/telephony/incoming` (POST)
   - **Call status callback**: `https://your-domain.com/api/telephony/status` (POST)

## 5. Llamenos တွင် သတ်မှတ်ပါ

1. အက်ဒ်မင်အဖြစ် ဝင်ရောက်ပါ
2. **ဆက်တင်များ** > **တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူ** သို့ သွားပါ
3. ဝန်ဆောင်မှုပေးသူ dropdown မှ **SignalWire** ကိုရွေးချယ်ပါ
4. အောက်ပါတို့ကို ထည့်သွင်းပါ:
   - **Account SID**: အဆင့် 3 မှ သင့် Project ID
   - **Auth Token**: အဆင့် 3 မှ သင့် API Token
   - **SignalWire Space**: သင့် Space အမည် (အမည်သာ၊ URL အပြည့်အစုံမဟုတ် -- ဥပမာ `myhotline`)
   - **Phone Number**: သင်ဝယ်ထားသော နံပါတ် (E.164 ပုံစံ)
5. **သိမ်းရန်** ကိုနှိပ်ပါ

## 6. သတ်မှတ်မှုကို စမ်းသပ်ပါ

သင့်ဟော့ပ်လိုင်းနံပါတ်ကို ခေါ်ဆိုပါ။ ဘာသာစကားရွေးချယ်မှုမီနူးနှင့် ခေါ်ဆိုမှုလမ်းကြောင်းကို သင်ကြားရပါမည်။

## WebRTC သတ်မှတ်ခြင်း (ချန်လှပ်နိုင်)

SignalWire WebRTC သည် Twilio နှင့် တူညီသော API သော့ပုံစံကို အသုံးပြုသည်:

1. သင့် SignalWire Dashboard တွင် **API** > **Tokens** အောက်ရှိ **API Key** တစ်ခုဖန်တီးပါ
2. **LaML Application** တစ်ခုဖန်တီးပါ:
   - **LaML** > **LaML Applications** သို့ သွားပါ
   - Voice URL ကို `https://your-domain.com/api/telephony/webrtc-incoming` သို့ သတ်မှတ်ပါ
   - Application SID ကို မှတ်သားပါ
3. Llamenos တွင် **ဆက်တင်များ** > **တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူ** သို့ သွားပါ
4. **WebRTC ခေါ်ဆိုခြင်း** ကို ဖွင့်ပါ
5. API Key SID၊ API Key Secret နှင့် Application SID တို့ကို ထည့်သွင်းပါ
6. **သိမ်းရန်** ကိုနှိပ်ပါ

## Twilio နှင့် ကွာခြားချက်များ

- **LaML vs TwiML**: SignalWire သည် LaML ကိုအသုံးပြုပြီး ၎င်းသည် TwiML နှင့် လုပ်ဆောင်ချက်အရ တူညီသည်။ Llamenos သည် ၎င်းကို အလိုအလျောက် ကိုင်တွယ်သည်။
- **Space URL**: API ခေါ်ဆိုမှုများသည် `api.twilio.com` အစား `{space}.signalwire.com` သို့ သွားသည်။ adapter သည် သင်ပေးသော Space အမည်မှတစ်ဆင့် ၎င်းကို ကိုင်တွယ်သည်။
- **စျေးနှုန်း**: SignalWire သည် ယေဘုယျအားဖြင့် အသံခေါ်ဆိုမှုများအတွက် Twilio ထက် 30-40% စျေးသက်သာသည်။
- **အင်္ဂါရပ် တူညီမှု**: Llamenos ၏ အင်္ဂါရပ်အားလုံး (မှတ်တမ်းတင်ခြင်း၊ စာသားပြောင်းခြင်း၊ CAPTCHA၊ အသံမေးလ်) သည် SignalWire ဖြင့် တူညီစွာ အလုပ်လုပ်သည်။

## ပြဿနာဖြေရှင်းခြင်း

- **"Space not found" အမှားများ**: Space အမည်ကို ပြန်စစ်ဆေးပါ (subdomain သာ၊ URL အပြည့်အစုံမဟုတ်)။
- **Webhook မအောင်မြင်ခြင်း**: သင့်ဆာဗာ URL သည် အများသုံးဝင်ရောက်နိုင်ပြီး HTTPS ကိုအသုံးပြုကြောင်း သေချာပါစေ။
- **API token ပြဿနာများ**: SignalWire တိုကင်များ သက်တမ်းကုန်နိုင်သည်။ အထောက်အထားစစ်ဆေးခြင်းအမှားများရပါက တိုကင်အသစ်တစ်ခုဖန်တီးပါ။
