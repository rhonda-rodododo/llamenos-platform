Twilio ارائه‌دهنده تلفنی پیش‌فرض برای Llámenos و ساده‌ترین راه برای شروع است. این راهنما شما را در ایجاد حساب، راه‌اندازی شماره تلفن و پیکربندی webhook راهنمایی می‌کند.

## پیش‌نیازها

- یک [حساب Twilio](https://www.twilio.com/try-twilio) (نسخه رایگان برای آزمایش کار می‌کند)
- نمونه Llámenos شما مستقر شده و از طریق یک آدرس عمومی قابل دسترسی است

## ۱. ایجاد حساب Twilio

در [twilio.com/try-twilio](https://www.twilio.com/try-twilio) ثبت نام کنید. ایمیل و شماره تلفن خود را تأیید کنید. Twilio اعتبار آزمایشی برای تست ارائه می‌دهد.

## ۲. خرید شماره تلفن

1. به **Phone Numbers** > **Manage** > **Buy a number** در کنسول Twilio بروید
2. یک شماره با قابلیت **Voice** در کد منطقه مورد نظر خود جستجو کنید
3. روی **Buy** کلیک کرده و تأیید کنید

این شماره را ذخیره کنید — آن را در تنظیمات مدیر Llámenos وارد خواهید کرد.

## ۳. دریافت Account SID و Auth Token

1. به [داشبورد کنسول Twilio](https://console.twilio.com) بروید
2. **Account SID** و **Auth Token** خود را در صفحه اصلی پیدا کنید
3. روی نماد چشم کلیک کنید تا Auth Token نمایش داده شود

## ۴. پیکربندی webhook

در کنسول Twilio، به پیکربندی شماره تلفن خود بروید:

1. به **Phone Numbers** > **Manage** > **Active Numbers** بروید
2. روی شماره خط تلفن خود کلیک کنید
3. در زیر **Voice Configuration**، تنظیم کنید:
   - **A call comes in**: Webhook، `https://your-domain.com/api/telephony/incoming`، HTTP POST
   - **Call status changes**: `https://your-domain.com/api/telephony/status`، HTTP POST

`your-domain.com` را با آدرس استقرار واقعی Llámenos خود جایگزین کنید.

## ۵. پیکربندی در Llámenos

1. به عنوان مدیر وارد شوید
2. به **تنظیمات** > **ارائه‌دهنده تلفنی** بروید
3. **Twilio** را از dropdown ارائه‌دهنده انتخاب کنید
4. وارد کنید:
   - **Account SID**: از مرحله ۳
   - **Auth Token**: از مرحله ۳
   - **شماره تلفن**: شماره‌ای که خریدید (قالب E.164، مثلاً `۱+۵۵۵۱۲۳۴۵۶۷`)
5. روی **ذخیره** کلیک کنید

## ۶. تست راه‌اندازی

از یک تلفن با شماره خط تلفن خود تماس بگیرید. باید منوی انتخاب زبان را بشنوید. اگر داوطلبان در شیفت دارید، تماس از طریق آنها زنگ خواهد خورد.

## راه‌اندازی WebRTC (اختیاری)

برای اینکه داوطلبان بتوانند به جای تلفن خود در مرورگر به تماس‌ها پاسخ دهند:

### ایجاد یک API Key

1. به **Account** > **API keys & tokens** در کنسول Twilio بروید
2. روی **Create API Key** کلیک کنید
3. نوع کلید **Standard** را انتخاب کنید
4. **SID** و **Secret** را ذخیره کنید — راز فقط یک بار نشان داده می‌شود

### ایجاد یک TwiML App

1. به **Voice** > **Manage** > **TwiML Apps** بروید
2. روی **Create new TwiML App** کلیک کنید
3. **Voice Request URL** را به `https://your-domain.com/api/telephony/webrtc-incoming` تنظیم کنید
4. ذخیره کرده و **App SID** را یادداشت کنید

### فعال‌سازی در Llámenos

1. به **تنظیمات** > **ارائه‌دهنده تلفنی** بروید
2. **WebRTC Calling** را روشن کنید
3. وارد کنید:
   - **API Key SID**: از API key که ایجاد کردید
   - **API Key Secret**: از API key که ایجاد کردید
   - **TwiML App SID**: از TwiML App که ایجاد کردید
4. روی **ذخیره** کلیک کنید

برای راه‌اندازی داوطلب و عیب‌یابی به [تماس مرورگر WebRTC](/docs/deploy/providers/webrtc) مراجعه کنید.

## عیب‌یابی

- **تماس‌ها نمی‌رسند**: آدرس webhook را تأیید کنید و مطمئن شوید سرور شما مستقر شده است. لاگ‌های خطای کنسول Twilio را بررسی کنید.
- **خطاهای "webhook نامعتبر"**: مطمئن شوید آدرس webhook از HTTPS استفاده می‌کند و TwiML معتبر برمی‌گرداند.
- **محدودیت‌های حساب آزمایشی**: حساب‌های آزمایشی فقط می‌توانند با شماره‌های تأیید شده تماس بگیرند. برای استفاده تولیدی به حساب پولی ارتقا دهید.
- **شکست اعتبارسنجی webhook**: اطمینان حاصل کنید Auth Token در Llámenos با Token موجود در کنسول Twilio مطابقت دارد.
