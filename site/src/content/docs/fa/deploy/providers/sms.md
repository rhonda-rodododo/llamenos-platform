پیام‌کوتاه در Llámenos از اعتبارنامه‌های موجود ارائه‌دهنده تلفنی صوتی شما استفاده مجدد می‌کند. هیچ سرویس SMS جداگانه‌ای لازم نیست — اگر قبلاً Twilio، SignalWire، Vonage یا Plivo را برای صدا پیکربندی کرده‌اید، SMS با همان حساب کار می‌کند.

## ارائه‌دهندگان پشتیبانی‌شده

| ارائه‌دهنده | پشتیبانی SMS | نکات |
|---|---|---|
| **Twilio** | بله | SMS دوطرفه کامل از طریق Twilio Messaging API |
| **SignalWire** | بله | سازگار با API Twilio — همان رابط |
| **Vonage** | بله | SMS از طریق Vonage REST API |
| **Plivo** | بله | SMS از طریق Plivo Message API |
| **Asterisk** | خیر | Asterisk از SMS بومی پشتیبانی نمی‌کند |

## ۱. فعال‌سازی SMS در تنظیمات مدیر

به **تنظیمات مدیر > کانال‌های پیام‌رسانی** بروید (یا از جادوگر راه‌اندازی در اولین ورود استفاده کنید) و **SMS** را روشن کنید.

تنظیمات SMS را پیکربندی کنید:
- **پیام پاسخ خودکار** — پیام خوش‌آمدگویی اختیاری برای مخاطبین اولین بار
- **پاسخ خارج از ساعت** — پیام اختیاری ارسال شده خارج از ساعت شیفت

## ۲. پیکربندی webhook

webhook SMS ارائه‌دهنده تلفنی خود را به سرور خود هدایت کنید:

```
POST https://your-domain.com/api/messaging/sms/webhook
```

### Twilio / SignalWire

۱. به کنسول Twilio > Phone Numbers > Active Numbers بروید
۲. شماره تلفن خود را انتخاب کنید
۳. در زیر **Messaging**، آدرس webhook را برای «A message comes in» به آدرس بالا تنظیم کنید
۴. روش HTTP را به **POST** تنظیم کنید

### Vonage

۱. به داشبورد Vonage API > Applications بروید
۲. برنامه خود را انتخاب کنید
۳. در زیر **Messages**، Inbound URL را به آدرس webhook بالا تنظیم کنید

### Plivo

۱. به کنسول Plivo > Messaging > Applications بروید
۲. یک برنامه پیام‌رسانی ایجاد یا ویرایش کنید
۳. Message URL را به آدرس webhook بالا تنظیم کنید
۴. برنامه را به شماره تلفن خود اختصاص دهید

## ۳. تست

یک پیام‌کوتاه به شماره خط تلفن خود ارسال کنید. باید مکالمه را در برگه **مکالمات** در پنل مدیر مشاهده کنید.

## نحوه کار

۱. یک پیام‌کوتاه به ارائه‌دهنده شما می‌رسد که یک webhook به سرور شما ارسال می‌کند
۲. سرور امضای webhook را اعتبارسنجی می‌کند (HMAC مخصوص ارائه‌دهنده)
۳. پیام تجزیه و در ConversationService ذخیره می‌شود
۴. داوطلبان شیفت از طریق رویدادهای رله WebSocket مطلع می‌شوند
۵. داوطلبان از برگه مکالمات پاسخ می‌دهند — پاسخ‌ها از طریق API SMS ارائه‌دهنده شما بازگردانده می‌شوند

## نکات امنیتی

- پیام‌های SMS از طریق شبکه حامل به صورت متن ساده عبور می‌کنند — ارائه‌دهنده و حامل‌های شما می‌توانند آنها را بخوانند
- پیام‌های ورودی پس از دریافت رمزنگاری و در پایگاه داده ذخیره می‌شوند
- شماره تلفن فرستندگان قبل از ذخیره‌سازی هش می‌شوند (حریم خصوصی)
- امضاهای webhook برای هر ارائه‌دهنده اعتبارسنجی می‌شوند (HMAC-SHA1 برای Twilio و غیره)
