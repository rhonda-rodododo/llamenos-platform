Plivo یک ارائه‌دهنده تلفنی ابری با قیمت مناسب و API ساده است. از کنترل تماس مبتنی بر XML مشابه TwiML استفاده می‌کند که یکپارچه‌سازی با Llámenos را آسان می‌کند.

## پیش‌نیازها

- یک [حساب Plivo](https://console.plivo.com/accounts/register/) (اعتبار آزمایشی موجود است)
- نمونه Llámenos شما مستقر شده و از طریق یک آدرس عمومی قابل دسترسی است

## ۱. ایجاد حساب Plivo

در [console.plivo.com](https://console.plivo.com/accounts/register/) ثبت نام کنید. پس از تأیید، می‌توانید **Auth ID** و **Auth Token** خود را در صفحه اصلی داشبورد پیدا کنید.

## ۲. خرید شماره تلفن

۱. به **Phone Numbers** > **Buy Numbers** در کنسول Plivo بروید
۲. کشور خود را انتخاب کرده و شماره‌هایی با قابلیت صدا جستجو کنید
۳. یک شماره خریداری کنید

## ۳. ایجاد یک XML Application

Plivo از «XML Applications» برای مسیریابی تماس‌ها استفاده می‌کند:

۱. به **Voice** > **XML Applications** بروید
۲. روی **Add New Application** کلیک کنید
۳. پیکربندی کنید:
   - **Application Name**: Llamenos Hotline
   - **Answer URL**: `https://your-domain.com/api/telephony/incoming` (POST)
   - **Hangup URL**: `https://your-domain.com/api/telephony/status` (POST)
۴. برنامه را ذخیره کنید

## ۴. پیوند شماره تلفن

۱. به **Phone Numbers** > **Your Numbers** بروید
۲. روی شماره خط تلفن خود کلیک کنید
۳. در زیر **Voice**، XML Application که در مرحله ۳ ایجاد کردید را انتخاب کنید
۴. ذخیره کنید

## ۵. پیکربندی در Llámenos

۱. به عنوان مدیر وارد شوید
۲. به **تنظیمات** > **ارائه‌دهنده تلفنی** بروید
۳. **Plivo** را از dropdown ارائه‌دهنده انتخاب کنید
۴. وارد کنید:
   - **Auth ID**: از داشبورد کنسول Plivo
   - **Auth Token**: از داشبورد کنسول Plivo
   - **شماره تلفن**: شماره‌ای که خریدید (قالب E.164)
۵. روی **ذخیره** کلیک کنید

## ۶. تست راه‌اندازی

از شماره خط تلفن خود تماس بگیرید. باید منوی انتخاب زبان را بشنوید و از طریق جریان تماس عادی مسیریابی شوید.

## راه‌اندازی WebRTC (اختیاری)

WebRTC Plivo از Browser SDK با اعتبارنامه‌های موجود شما استفاده می‌کند:

۱. به **Voice** > **Endpoints** در کنسول Plivo بروید
۲. یک endpoint جدید ایجاد کنید (این به عنوان هویت تلفن مرورگر عمل می‌کند)
۳. در Llámenos، به **تنظیمات** > **ارائه‌دهنده تلفنی** بروید
۴. **WebRTC Calling** را روشن کنید
۵. روی **ذخیره** کلیک کنید

آداپتور توکن‌های HMAC محدود به زمان را از Auth ID و Auth Token شما برای احراز هویت امن مرورگر تولید می‌کند.

## نکات مخصوص Plivo

- **XML در مقابل TwiML**: Plivo از فرمت XML خود برای کنترل تماس استفاده می‌کند که مشابه اما نه یکسان با TwiML است. آداپتور Llámenos به طور خودکار XML صحیح Plivo را تولید می‌کند.
- **Answer URL در مقابل Hangup URL**: Plivo کنترل‌کننده تماس اولیه (Answer URL) را از کنترل‌کننده پایان تماس (Hangup URL) جدا می‌کند، برخلاف Twilio که از یک callback وضعیت واحد استفاده می‌کند.
- **محدودیت‌های نرخ**: Plivo محدودیت‌های نرخ API دارد که بر اساس سطح حساب متفاوت است. برای خطوط تلفن پرحجم، با پشتیبانی Plivo تماس بگیرید تا محدودیت‌ها افزایش یابند.

## عیب‌یابی

- **«Auth ID نامعتبر»**: Auth ID آدرس ایمیل شما نیست. آن را در صفحه اصلی داشبورد کنسول Plivo پیدا کنید.
- **تماس‌ها مسیریابی نمی‌شوند**: بررسی کنید که شماره تلفن به XML Application صحیح پیوند داده شده است.
- **خطاهای Answer URL**: Plivo انتظار پاسخ‌های XML معتبر دارد. لاگ‌های سرور خود را برای خطاهای پاسخ بررسی کنید.
- **محدودیت‌های تماس خروجی**: حساب‌های آزمایشی محدودیت‌هایی در تماس خروجی دارند. برای استفاده تولیدی ارتقا دهید.
