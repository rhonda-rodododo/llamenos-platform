Llamenos підтримує обмін повідомленнями WhatsApp Business через Meta Cloud API (Graph API v21.0). WhatsApp дозволяє надсилати багаті повідомлення з підтримкою тексту, зображень, документів, аудіо та інтерактивних повідомлень.

## Передумови

- [Обліковий запис Meta Business](https://business.facebook.com)
- Телефонний номер WhatsApp Business API
- Додаток розробника Meta з увімкненим продуктом WhatsApp

## Режими інтеграції

Llamenos підтримує два режими інтеграції WhatsApp:

### Meta Direct (рекомендовано)

Підключіться безпосередньо до Meta Cloud API. Забезпечує повний контроль та всі функції.

**Необхідні облікові дані:**
- **Phone Number ID** — ID телефонного номера WhatsApp Business
- **Business Account ID** — ID облікового запису Meta Business
- **Access Token** — довгостроковий токен доступу Meta API
- **Verify Token** — власний рядок, який ви обираєте для перевірки вебхука
- **App Secret** — секрет вашого додатка Meta (для перевірки підпису вебхука)

### Режим Twilio

Якщо ви вже використовуєте Twilio для голосу, ви можете маршрутизувати WhatsApp через свій обліковий запис Twilio. Простіше налаштування, але деякі функції можуть бути обмежені.

**Необхідні облікові дані:**
- Ваші наявні Twilio Account SID, Auth Token і Twilio-підключений відправник WhatsApp

## 1. Створіть додаток Meta

1. Перейдіть до [developers.facebook.com](https://developers.facebook.com)
2. Створіть новий додаток (тип: Business)
3. Додайте продукт **WhatsApp**
4. У WhatsApp > Getting Started запишіть свій **Phone Number ID** та **Business Account ID**
5. Згенеруйте постійний токен доступу (Settings > Access Tokens)

## 2. Налаштуйте вебхук

У панелі керування розробника Meta:

1. Перейдіть до WhatsApp > Configuration > Webhook
2. Встановіть Callback URL на:
   ```
   https://your-domain.com/api/messaging/whatsapp/webhook
   ```
3. Встановіть Verify Token на той самий рядок, який ви введете в налаштуваннях адміністратора Llamenos
4. Підпишіться на поле вебхука `messages`

Meta надішле GET-запит для перевірки вебхука. Ваш сервер відповість challenge, якщо verify token збігається.

## 3. Увімкніть WhatsApp у налаштуваннях адміністратора

Перейдіть до **Admin Settings > Messaging Channels** (або скористайтеся майстром налаштування) та увімкніть перемикач **WhatsApp**.

Оберіть режим **Meta Direct** або **Twilio** та введіть необхідні облікові дані.

Налаштуйте додаткові параметри:
- **Auto-response message** — надсилається першим контактам
- **After-hours response** — надсилається поза годинами зміни

## 4. Перевірка

Надішліть повідомлення WhatsApp на ваш номер Business. Розмова повинна з'явитися у вкладці **Conversations**.

## 24-годинне вікно обміну повідомленнями

WhatsApp дотримується 24-годинного вікна обміну повідомленнями:
- Ви можете відповідати користувачеві протягом 24 годин після його останнього повідомлення
- Після 24 годин ви повинні використовувати схвалене **шаблонне повідомлення**, щоб відновити розмову
- Llamenos обробляє це автоматично — якщо вікно минуло, надсилається шаблонне повідомлення для перезапуску розмови

## Підтримка медіа

WhatsApp підтримує багаті медіаповідомлення:
- **Зображення** (JPEG, PNG)
- **Документи** (PDF, Word тощо)
- **Аудіо** (MP3, OGG)
- **Відео** (MP4)
- Спільний доступ до **місцезнаходження**
- **Інтерактивні** кнопки та повідомлення зі списком

Медіавкладення відображаються безпосередньо у вікні розмови.

## Примітки щодо безпеки

- WhatsApp використовує наскрізне шифрування між користувачем та інфраструктурою Meta
- Технічно Meta може отримати доступ до вмісту повідомлень на своїх серверах
- Повідомлення шифруються при отриманні та зберігаються в базі даних
- Підписи вебхуків перевіряються за допомогою HMAC-SHA256 із вашим app secret
- Для максимальної конфіденційності розгляньте можливість використання Signal замість WhatsApp
