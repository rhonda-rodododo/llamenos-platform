Twilio — це телефонний провайдер за замовчуванням для Llamenos, і з ним найлегше почати роботу. Цей посібник проведе вас через створення облікового запису, налаштування номера телефону та конфігурацію вебхуків.

## Передумови

- [Обліковий запис Twilio](https://www.twilio.com/try-twilio) (безкоштовна пробна версія підходить для тестування)
- Ваш екземпляр Llamenos розгорнуто та доступний через публічний URL

## 1. Створіть обліковий запис Twilio

Зареєструйтеся на [twilio.com/try-twilio](https://www.twilio.com/try-twilio). Підтвердьте свою електронну пошту та номер телефону. Twilio надає пробний кредит для тестування.

## 2. Купіть номер телефону

1. Перейдіть до **Phone Numbers** > **Manage** > **Buy a number** у консолі Twilio
2. Знайдіть номер з можливістю **Voice** у потрібному коді міста
3. Натисніть **Buy** та підтвердьте

Збережіть цей номер — ви введете його в налаштуваннях адміністратора Llamenos.

## 3. Отримайте SID облікового запису та токен аутентифікації

1. Перейдіть до [панелі керування Twilio Console](https://console.twilio.com)
2. Знайдіть **Account SID** та **Auth Token** на головній сторінці
3. Натисніть на іконку ока, щоб показати Auth Token

## 4. Налаштуйте вебхуки

У консолі Twilio перейдіть до конфігурації вашого номера телефону:

1. Перейдіть до **Phone Numbers** > **Manage** > **Active Numbers**
2. Натисніть на номер вашої гарячої лінії
3. У розділі **Voice Configuration** встановіть:
   - **A call comes in**: Webhook, `https://your-domain.com/api/telephony/incoming`, HTTP POST
   - **Call status changes**: `https://your-domain.com/api/telephony/status`, HTTP POST

Замініть `your-domain.com` на фактичний URL вашого розгортання Llamenos.

## 5. Налаштуйте в Llamenos

1. Увійдіть як адміністратор
2. Перейдіть до **Налаштування** > **Телефонний провайдер**
3. Виберіть **Twilio** зі списку провайдерів
4. Введіть:
   - **Account SID**: з кроку 3
   - **Auth Token**: з кроку 3
   - **Номер телефону**: номер, який ви купили (формат E.164, наприклад, `+15551234567`)
5. Натисніть **Зберегти**

## 6. Перевірте налаштування

Зателефонуйте на номер вашої гарячої лінії з телефона. Ви маєте почути меню вибору мови. Якщо у вас є волонтери на зміні, дзвінок буде перенаправлено.

## Налаштування WebRTC (необов'язково)

Щоб дозволити волонтерам відповідати на дзвінки в браузері замість телефона:

### Створіть API Key

1. Перейдіть до **Account** > **API keys & tokens** у консолі Twilio
2. Натисніть **Create API Key**
3. Виберіть тип ключа **Standard**
4. Збережіть **SID** та **Secret** — секрет показується лише один раз

### Створіть TwiML App

1. Перейдіть до **Voice** > **Manage** > **TwiML Apps**
2. Натисніть **Create new TwiML App**
3. Встановіть **Voice Request URL** на `https://your-domain.com/api/telephony/webrtc-incoming`
4. Збережіть та запишіть **App SID**

### Увімкніть у Llamenos

1. Перейдіть до **Налаштування** > **Телефонний провайдер**
2. Увімкніть **Веб-дзвінки через WebRTC**
3. Введіть:
   - **API Key SID**: з API ключа, який ви створили
   - **API Key Secret**: з API ключа, який ви створили
   - **TwiML App SID**: з TwiML App, який ви створили
4. Натисніть **Зберегти**

Перегляньте [Веб-дзвінки через WebRTC](/docs/deploy/providers/webrtc) для налаштування волонтерів та усунення несправностей.

## Усунення несправностей

- **Дзвінки не надходять**: Перевірте, чи правильний URL вебхука та чи ваш сервер розгорнуто. Перевірте журнали помилок у консолі Twilio.
- **Помилки "Invalid webhook"**: Переконайтеся, що URL вебхука використовує HTTPS і повертає дійсний TwiML.
- **Обмеження пробного облікового запису**: Пробні облікові записи можуть телефонувати лише на підтверджені номери. Оновіть до платного облікового запису для продуктивного використання.
- **Помилки валідації вебхуків**: Переконайтеся, що Auth Token у Llamenos збігається з тим, що в консолі Twilio.
