---
title: "Налаштування: SMS"
description: Увімкніть вхідні та вихідні SMS-повідомлення через вашого телефонного провайдера.
---

SMS у Llamenos використовує облікові дані вашого наявного телефонного провайдера. Окремий SMS-сервіс не потрібен — якщо ви вже налаштували Twilio, SignalWire, Vonage або Plivo для голосу, SMS працюватиме з тим самим обліковим записом.

## Підтримувані провайдери

| Провайдер | Підтримка SMS | Примітки |
|-----------|--------------|----------|
| **Twilio** | Так | Повноцінні двосторонні SMS через Twilio Messaging API |
| **SignalWire** | Так | Сумісний із Twilio API — той самий інтерфейс |
| **Vonage** | Так | SMS через Vonage REST API |
| **Plivo** | Так | SMS через Plivo Message API |
| **Asterisk** | Ні | Asterisk не підтримує власні SMS |

## 1. Увімкніть SMS у налаштуваннях адміністратора

Перейдіть до **Admin Settings > Messaging Channels** (або скористайтеся майстром налаштування під час першого входу) та увімкніть перемикач **SMS**.

Налаштуйте параметри SMS:
- **Auto-response message** — необов'язкове привітальне повідомлення, що надсилається першим контактам
- **After-hours response** — необов'язкове повідомлення, що надсилається поза годинами зміни

## 2. Налаштуйте вебхук

Направте SMS-вебхук вашого телефонного провайдера на ваш сервер:

```
POST https://your-domain.com/api/messaging/sms/webhook
```

### Twilio / SignalWire

1. Перейдіть до Twilio Console > Phone Numbers > Active Numbers
2. Оберіть свій телефонний номер
3. У розділі **Messaging** встановіть вебхук URL для "A message comes in" на URL-адресу вище
4. Встановіть HTTP-метод на **POST**

### Vonage

1. Перейдіть до Vonage API Dashboard > Applications
2. Оберіть ваш додаток
3. У розділі **Messages** встановіть Inbound URL на вебхук URL вище

### Plivo

1. Перейдіть до Plivo Console > Messaging > Applications
2. Створіть або відредагуйте додаток для обміну повідомленнями
3. Встановіть Message URL на вебхук URL вище
4. Призначте додаток вашому телефонному номеру

## 3. Перевірка

Надішліть SMS на номер гарячої лінії. Ви повинні побачити розмову у вкладці **Conversations** в панелі адміністратора.

## Як це працює

1. SMS надходить до вашого провайдера, який надсилає вебхук на ваш сервер
2. Сервер перевіряє підпис вебхука (провайдерський HMAC)
3. Повідомлення розбирається та зберігається в ConversationService
4. Волонтери на зміні отримують сповіщення через події ретрансляції WebSocket
5. Волонтери відповідають із вкладки Conversations — відповіді надсилаються назад через SMS API вашого провайдера

## Примітки щодо безпеки

- SMS-повідомлення передаються мережею оператора у вигляді відкритого тексту — ваш провайдер та оператори можуть їх читати
- Вхідні повідомлення шифруються при отриманні та зберігаються в базі даних
- Номери телефонів відправників хешуються перед зберіганням (конфіденційність)
- Підписи вебхуків перевіряються для кожного провайдера (HMAC-SHA1 для Twilio тощо)
