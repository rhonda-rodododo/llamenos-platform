Llamenos підтримує кількох телефонних провайдерів через інтерфейс **TelephonyAdapter**. Ви можете перемикати провайдерів у будь-який час з налаштувань адміністратора без зміни коду додатка.

## SIP міст

Самостійно розміщені провайдери (Asterisk, FreeSWITCH, Kamailio) доступні через службу `sip-bridge`. Встановіть змінну середовища `PBX_TYPE`, щоб вибрати бекенд:

```env
PBX_TYPE=asterisk      # Asterisk ARI
PBX_TYPE=freeswitch    # FreeSWITCH ESL
PBX_TYPE=kamailio      # Kamailio
```

## Як налаштувати

1. Перейдіть до **Налаштування** в бічній панелі адміністратора
2. Відкрийте розділ **Телефонний провайдер**
3. Виберіть свого провайдера зі списку
4. Введіть необхідні облікові дані
5. Встановіть номер телефону гарячої лінії у форматі E.164 (наприклад, `+15551234567`)
6. Натисніть **Зберегти**
7. Налаштуйте вебхуки в консолі вашого провайдера
