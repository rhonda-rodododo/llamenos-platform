title: "Налаштування: Vonage"

---

Vonage (раніше Nexmo) пропонує широке міжнародне покриття та конкурентоспроможні ціни. Він використовує іншу модель API, ніж Twilio — додатки Vonage (Applications) об'єднують ваш номер, вебхуки та облікові дані.

## Передумови

- [Обліковий запис Vonage](https://dashboard.nexmo.com/sign-up) (доступний безкоштовний кредит)
- Ваш екземпляр Llamenos розгорнуто та доступний за публічною URL-адресою

## 1. Створіть обліковий запис Vonage

Зареєструйтесь у [панелі керування Vonage API](https://dashboard.nexmo.com/sign-up). Підтвердьте свій обліковий запис і запишіть **API Key** та **API Secret** з головної сторінки панелі керування.

## 2. Придбайте телефонний номер

1. У панелі керування Vonage перейдіть до **Numbers** > **Buy numbers**
2. Оберіть свою країну та номер із можливістю **Voice**
3. Придбайте номер

## 3. Створіть додаток Vonage (Application)

Vonage групує налаштування в "Applications":

1. Перейдіть до **Applications** > **Create a new application**
2. Введіть назву (наприклад, "Llamenos Hotline")
3. У розділі **Voice** увімкніть його та встановіть:
   - **Answer URL**: `https://your-domain.com/api/telephony/incoming` (POST)
   - **Event URL**: `https://your-domain.com/api/telephony/status` (POST)
4. Натисніть **Generate new application**
5. Збережіть **Application ID**, показаний на сторінці підтвердження
6. Завантажте файл **private key** — вам знадобиться його вміст для налаштування

## 4. Прив'яжіть телефонний номер

1. Перейдіть до **Numbers** > **Your numbers**
2. Натисніть значок шестерні поруч із номером гарячої лінії
3. У розділі **Voice** оберіть додаток, створений на кроці 3
4. Натисніть **Save**

## 5. Налаштуйте в Llamenos

1. Увійдіть як адміністратор
2. Перейдіть до **Settings** > **Telephony Provider**
3. Оберіть **Vonage** у спадному меню провайдера
4. Введіть:
   - **API Key**: з головної сторінки панелі керування Vonage
   - **API Secret**: з головної сторінки панелі керування Vonage
   - **Application ID**: з кроку 3
   - **Phone Number**: номер, який ви придбали (формат E.164)
5. Натисніть **Save**

## 6. Перевірте налаштування

Подзвоніть на номер гарячої лінії. Ви повинні почути меню вибору мови. Переконайтеся, що виклики маршрутизуються до волонтерів, які перебувають на зміні.

## Налаштування WebRTC (необов'язково)

WebRTC від Vonage використовує облікові дані додатка, які ви вже створили:

1. У Llamenos перейдіть до **Settings** > **Telephony Provider**
2. Увімкніть перемикач **WebRTC Calling**
3. Вставте вміст **Private Key** (повний PEM-текст із файлу, який ви завантажили)
4. Натисніть **Save**

Application ID уже налаштовано. Vonage генерує RS256 JWT за допомогою приватного ключа для автентифікації в браузері.

## Примітки щодо Vonage

- **NCCO проти TwiML**: Vonage використовує NCCO (Nexmo Call Control Objects) у форматі JSON замість XML-розмітки. Адаптер Llamenos автоматично генерує правильний формат.
- **Формат Answer URL**: Vonage очікує, що Answer URL поверне JSON (NCCO), а не XML. Це обробляється адаптером.
- **Event URL**: Vonage надсилає події виклику (дзвінок, відповідь, завершення) на Event URL у вигляді JSON POST-запитів.
- **Безпека приватного ключа**: Приватний ключ зберігається в зашифрованому вигляді. Він ніколи не залишає сервер — використовується лише для генерації короткочасних JWT-токенів.

## Вирішення проблем

- **"Application not found"**: Переконайтеся, що Application ID точно збігається. Ви можете знайти його у розділі **Applications** у панелі керування Vonage.
- **Вхідні виклики не надходять**: Переконайтеся, що телефонний номер прив'язаний до правильного додатка (крок 4).
- **Помилки приватного ключа**: Вставте повний PEM-вміст, включаючи рядки `-----BEGIN PRIVATE KEY-----` та `-----END PRIVATE KEY-----`.
- **Формат міжнародних номерів**: Vonage вимагає формат E.164. Вкажіть `+` та код країни.
