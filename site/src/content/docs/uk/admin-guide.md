Як адміністратор, ви керуєте всім: волонтерами, змінами, каналами зв'язку, розмовами, звітами, списками блокувань та користувацькими полями. Цей посібник охоплює ключові робочі процеси адміністратора.

## Вхід у систему

Увійдіть за допомогою `nsec` (секретного ключа WebSocket), згенерованого під час [налаштування](/docs/deploy). Сторінка входу приймає формат nsec (`nsec1...`). Ваш браузер підписує запит ключем — секрет ніколи не залишає пристрій.

За бажанням зареєструйте ключ доступу WebAuthn у налаштуваннях для безпарольного входу на інших пристроях.

## Майстер налаштування

Під час першого входу додаток перенаправляє вас до **майстра налаштування** — покрокового процесу:

1. **Назвіть свою гарячу лінію** — встановіть назву, яку бачитимуть користувачі
2. **Виберіть канали** — увімкніть/вимкніть голосовий зв'язок, SMS, WhatsApp, Signal та звіти
3. **Налаштуйте провайдерів** — введіть облікові дані для кожного увімкненого каналу
4. **Підтвердження** — перевірте налаштування та завершіть налаштування

Після завершення майстра прапорець `setupCompleted` встановлюється, і майстер більше не з'явиться. Ви завжди можете змінити ці налаштування пізніше на сторінці налаштувань.

## Керування волонтерами

Перейдіть до розділу **Волонтери** у бічній панелі, щоб:

- **Додати волонтера** — генерує нову ключову пару WebSocket. Надішліть nsec волонтеру в безпечний спосіб (він показується лише один раз).
- **Створити запрошення** — генерує одноразове посилання. Процес запрошення включає вибір ролі (волонтер, адміністратор або репортер).
- **Редагувати** — оновити ім'я, номер телефону та роль.
- **Видалити** — деактивувати доступ волонтера.

Номери телефонів волонтерів видимі лише адміністраторам. Вони використовуються для паралельного дзвінка, коли волонтер на зміні.

## Керування репортерами

Репортери — це спеціальна роль для людей, які надсилають підказки або звіти через платформу. Вони мають обмежений доступ — можуть переглядати лише власні звіти та сторінку довідки.

Щоб додати репортера:
1. Створіть запрошення та виберіть роль **Репортер**
2. Надішліть посилання репортеру — він створить власні облікові дані
3. Репортери входять у систему та бачать спрощений інтерфейс лише зі звітами та довідкою

## Налаштування змін

Перейдіть до розділу **Зміни**, щоб створити повторювані розклади:

1. Натисніть **Додати зміну**
2. Встановіть назву, виберіть дні тижня та час початку/завершення
3. Призначте волонтерів за допомогою пошуку з множинним вибором
4. Збережіть — система автоматично маршрутизуватиме дзвінки до волонтерів активної зміни

Налаштуйте **Резервну групу** внизу сторінки змін. Ці волонтери отримуватимуть дзвінки, коли жодна запланована зміна не активна.

## Списки блокувань

Перейдіть до розділу **Блокування**, щоб керувати заблокованими номерами телефонів:

- **Одиничний запис** — введіть номер телефону у форматі E.164 (наприклад, +15551234567)
- **Масове імпортування** — вставте кілька номерів, по одному на рядок
- **Видалити** — розблокувати номер миттєво

Блокування набирають чинності негайно. Заблоковані абоненти чують повідомлення про відмову та від'єднуються.

## Розмови

Коли канали обміну повідомленнями (SMS, WhatsApp, Signal) увімкнено, у бічній панелі з'являється посилання **Розмови**. Тут відображаються всі розмови в потоках з усіх каналів обміну повідомленнями.

Кожна розмова показує:
- Бульбашки повідомлень з мітками часу та напрямком (вхідне/вихідне)
- Канал, через який надійшло повідомлення (SMS, WhatsApp, Signal)
- Оновлення в реальному часі через WebSocket — нові повідомлення з'являються миттєво

Розмови створюються автоматично при надходженні вхідного повідомлення. Волонтери можуть відповідати безпосередньо з перегляду розмови.

## Звіти

Коли канал звітів увімкнено, адміністратори можуть переглядати всі подані звіти:

- **Список звітів** — показує всі звіти з назвою, категорією, статусом та датою подання
- **Відстеження статусу** — звіти проходять статуси: відкрито → взято в роботу → вирішено
- **Взяти звіт** — призначити себе для роботи над звітом
- **Відповіді в потоці** — відповідайте репортерам зашифрованими повідомленнями
- **Вкладення файлів** — репортери можуть завантажувати зашифровані файли разом зі своїми звітами

Вміст тіла звіту та вкладення файлів шифруються за допомогою ECIES — сервер ніколи не бачить зміст звіту у відкритому вигляді.

## Налаштування дзвінків

У розділі **Налаштування** ви знайдете кілька підрозділів:

### Захист від спаму

- **Голосова CAPTCHA** — увімкнути/вимкнути. Коли увімкнено, абоненти повинні ввести випадковий 4-значний код.
- **Обмеження швидкості** — увімкнути/вимкнути. Обмежує дзвінки з одного номера телефону в межах ковзного часового вікна.

### Транскрипція

- **Глобальне перемикання** — увімкнути/вимкнути транскрипцію Whisper для всіх дзвінків.
- Окремі волонтери також можуть відмовитися у власних налаштуваннях.

### Налаштування дзвінків

- **Час очікування в черзі** — скільки абоненти чекають перед переходом на голосову пошту (30-300 секунд).
- **Максимальна тривалість голосової пошти** — максимальна довжина запису (30-300 секунд).

### Користувацькі поля нотаток

Визначте структуровані поля, які з'являтимуться у формі створення нотаток:

- Підтримувані типи: текст, число, вибір (список), прапорець, текстова область
- Налаштування валідації: обов'язкове, мін./макс. довжина, мін./макс. значення
- Контроль видимості: оберіть, які поля можуть бачити та редагувати волонтери
- Змінюйте порядок полів за допомогою стрілок вгору/вниз
- Максимум 20 полів, максимум 50 варіантів на одне поле вибору

Значення користувацьких полів шифруються разом із вмістом нотатки. Сервер ніколи їх не бачить.

### Голосові підказки

Запишіть власні аудіопідказки IVR для кожної підтримуваної мови. Система використовує ваші записи для привітання, CAPTCHA, черги та голосової пошти. Якщо запису немає, використовується синтез мовлення.

### Канали обміну повідомленнями

Налаштуйте канали SMS, WhatsApp та Signal:

- **SMS** — увімкнути/вимкнути, налаштувати вітальне повідомлення для автоматичних відповідей. Використовує того ж провайдера, що й голосова телефонія (Twilio, SignalWire, Vonage або Plivo).
- **WhatsApp** — увімкнути/вимкнути, ввести облікові дані Meta Cloud API (токен доступу, токен перевірки, ID номера телефону). Підтримує шаблонні повідомлення для ініціювання розмов у 24-годинному вікні обміну повідомленнями.
- **Signal** — увімкнути/вимкнути, налаштувати URL моста signal-cli-rest-api та номер телефону. Включає моніторинг працездатності з плавною деградацією.

Кожен канал має власну кінцеву точку вебхука — дивіться [Початок роботи](/docs/deploy) для URL, які потрібно налаштувати.

### Політика WebAuthn

За бажанням вимагайте ключі доступу для адміністраторів, волонтерів або обох. Якщо вимога встановлена, користувачі повинні зареєструвати ключ доступу перед використанням додатка.

## Довідка в додатку

Сторінка **Довідка** надає:
- Розділи поширених запитань: Початок роботи, Дзвінки та зміни, Нотатки та шифрування, Адміністрування
- Посібники для різних ролей: адміністраторів, волонтерів та репортерів
- Картки швидкої довідки щодо клавіатурних скорочень та безпеки
- Згортувані пункти поширених запитань

Панель керування адміністратора також показує **Контрольний список початку роботи**, який відстежує прогрес налаштування (налаштування каналів, додавання волонтерів, створення змін тощо).

## Журнал аудиту

Сторінка **Журнал аудиту** показує хронологічний список подій системи: входи, відповіді на дзвінки, створення нотаток, зміни налаштувань та дії адміністраторів. Записи містять хешовані IP-адреси та метадані країни. Використовуйте посторінкову навігацію для перегляду історії.

## Історія дзвінків

Сторінка **Дзвінки** показує всі дзвінки зі статусом, тривалістю та призначеним волонтером. Фільтруйте за діапазоном дат або шукайте за номером телефону. Експортуйте дані у форматі JSON, сумісному з GDPR.
