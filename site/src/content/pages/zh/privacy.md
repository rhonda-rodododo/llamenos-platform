**生效日期：2026年5月18日**

Llámenos是开源危机响应软件。本政策适用于Llámenos iOS应用及由您的Hub管理员运营的后端服务。不适用于第三方运营的Hub——每个Hub管理员对其自身的数据做法负责。

---

## 我们收集什么

### 账户和身份数据

- **设备公钥** — 您设备特有的密码学标识符。绝不在您的Hub之外共享。
- **推送通知令牌** — 仅用于向您的设备发送通话提醒。定期轮换。
- **角色和Hub成员资格** — 您属于哪些Hub以及您分配的角色（志愿者、管理员）。
- **设备元数据** — 设备型号、操作系统版本和应用版本。

### 活动数据

- **通话元数据** — 时间戳、通话时长、哪位志愿者接听。不包括通话内容。
- **值班记录** — 您排班的值班及是否活跃。
- **审计日志条目** — 应用中执行的操作。仅对管理员可见。
- **安全事件** — 设备注册、撤销、会话活动和账户变更。

### 您创建的内容 — 端对端加密

- **通话笔记和转录** — 书面笔记和浏览器生成的转录。
- **报告和案例记录** — 结构化报告、自定义字段、文件附件和案例历史。
- **联系人记录** — 来电者联系信息（如有记录）。
- **消息** — 路由到您Hub的入站短信。

**服务器仅以密文形式存储此内容。** 服务器运营商、托管提供商或Llámenos均无法读取。

### 广播/订阅者数据

订阅者电话号码以哈希标识符形式存储——不是明文电话号码。发送群发消息时，服务器短暂处理明文内容以进行投递。投递后不存储内容。

### 恢复组数据

如果您配置恢复组，服务器存储加密的份额片段（每个片段加密给特定份额持有者的设备——服务器无法读取）。服务器无法重建您的恢复密钥。

---

## 我们如何使用数据

- **运营应用** — 路由通话、启用记笔记、管理值班和报告。
- **安全** — 检测滥用、维护禁止列表、速率限制。
- **审计** — 为管理员提供应用活动的审计日志（不包括内容）。
- **恢复** — 存储加密片段以便恢复组可以帮助用户恢复访问。

我们不将您的数据用于广告。我们不出售或共享您的数据用于商业目的。

---

## 端对端加密

所有笔记内容、转录、报告、联系人记录和入站消息均端对端加密。

| 数据类型 | 服务器可读？ | 传票可获取 |
|---------|-----------|----------|
| 通话笔记 | 否 | 仅密文 |
| 转录 | 否 | 仅密文 |
| 报告 | 否 | 仅密文 |
| 案例记录 | 否 | 仅密文 |
| 入站消息 | 否 | 仅密文 |
| 恢复片段 | 否 | 仅密文 |
| 出站群发消息 | **是，投递时短暂** | 是（发送时明文） |
| 通话元数据 | 是 | 是 |
| 您的设备公钥 | 是 | 是 |
| 安全事件 | 是 | 是 |

## 数据保留

### 您创建的内容

保留至您或管理员明确删除，或您的Hub关闭。

### 群发消息

投递后不存储内容。仅保留投递状态记录。

### 通话元数据和审计日志

根据您的Hub管理员配置保留。

### 恢复片段

保留至您删除恢复组配置或您的账户被清除。

### 推送令牌

当您退出登录或卸载应用时删除。

---

## 账户删除

您有权请求永久删除您的账户。

### 删除的作用

1. **首先销毁密钥**：您的设备加密密钥立即被销毁，使所有内容永久不可读。
2. **删除账户记录**：您的账户记录、设备注册、推送令牌和角色分配被删除。
3. **审计条目密码销毁**：您审计日志条目的加密密钥被销毁。
4. **加密内容重新封装**：您编写的笔记和报告为剩余授权读者重新加密。

### 用户删除

可从所有平台的账户设置中使用。默认有延迟（由Hub管理员配置，最少24小时，最多7天）。您可以在此期间取消。

### 紧急删除

联合批准人可以批准紧急删除，将延迟减少到最少4小时。

## 第三方服务

Llámenos与电话运营商集成用于通话路由。

**电话提供商收到什么**：来电者的电话号码、时长和时间戳。不接收笔记、转录或您在应用中创建的任何内容。

**消息提供商用于群发消息收到什么**：消息内容（SMS、WhatsApp、RCS）——提供商必须接收明文才能投递。对于Signal广播，内容通过Signal网络端对端加密投递。

## 您在GDPR下的权利

Llámenos由总部位于欧盟的组织开发。如果您在欧洲经济区：

- **访问权** — 请求您个人数据的副本
- **更正权** — 更正不准确的数据
- **删除权** — 请求永久删除您的账户和所有相关数据
- **数据可携权** — 以机器可读格式接收您的数据
- **反对权** — 反对基于合法利益的处理
- **限制处理权** — 请求限制处理
- **撤回同意权** — 随时撤回同意

行使这些权利，请联系您的Hub管理员或发送邮件至[privacy@llamenos-platform.com](mailto:privacy@llamenos-platform.com)。
