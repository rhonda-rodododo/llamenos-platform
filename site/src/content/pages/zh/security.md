## 如果您的托管服务商收到传票

| 可以提供 | 无法提供 |
|---------|---------|
| 通话/消息元数据（时间、时长） | 笔记内容、转录、报告正文 |
| 加密的数据库数据 | 志愿者姓名（端对端加密） |
| 哪些志愿者账户何时处于活跃状态 | 联系人目录记录（端对端加密） |
| 群发消息投递记录 | 消息内容（到达时加密，以密文形式存储） |
| | 解密密钥（受您的PIN、身份提供商账户及可选硬件安全密钥保护） |
| | 每条笔记的加密密钥（临时性——封装后销毁） |
| | 用于还原电话号码哈希值的HMAC密钥 |
| | 恢复片段内容（加密，服务器无法读取） |

**服务器存储其无法读取的数据。** 元数据（时间、时长、账户）可见。内容（说了什么、写了什么、您的联系人是谁）不可见。

## 按功能分类

您的隐私暴露程度取决于您启用的渠道：

### 语音通话

| 如果您使用... | 第三方可访问 | 服务器可访问 | 端对端加密内容 |
|-------------|------------|------------|--------------|
| Twilio/SignalWire/Vonage/Plivo | 通话音频（实时）、通话记录 | 通话元数据 | 笔记、转录 |
| 自托管 Asterisk | 无（您自己控制） | 通话元数据 | 笔记、转录 |
| 浏览器对浏览器（WebRTC） | 无 | 通话元数据 | 笔记、转录 |

**电话运营商传票**：他们拥有通话详细记录（时间、号码、时长），但没有通话笔记或转录。默认情况下录音已禁用。

**转录**：转录完全在您的浏览器中使用本地AI进行。**音频永远不会离开您的设备。**

### 文本消息（一对一）

| 渠道 | 提供商访问 | 服务器存储 | 备注 |
|-----|----------|----------|------|
| SMS | 您的电话运营商读取所有消息 | **加密** | 提供商保留原始消息 |
| WhatsApp | Meta读取所有消息 | **加密** | 提供商保留原始消息 |
| Signal | Signal网络是端对端加密；桥接服务到达时重新加密 | **加密** | 可用时的首选路径 |

**Signal优先路由**：当收件人有Signal时，消息会自动通过Signal路由——您的电话运营商看不到内容。对于SMS，默认只发送通用通知（无消息正文）。

**消息在到达您的服务器时立即加密。** 服务器只存储密文。

### 群发和广播消息

管理员可以通过SMS、WhatsApp、Signal或RCS向订阅者发送群发消息。

**重要：发出的群发消息在服务器端不是端对端加密的。** 要将消息发送给SMS或WhatsApp订阅者，服务器必须短暂处理明文内容并将其传递给消息提供商。

| 渠道 | 发送时服务器访问 | 提供商访问 | 投递后 |
|----|--------------|----------|-------|
| SMS群发 | 明文（短暂，用于投递） | 完整内容 | 提供商保留 |
| WhatsApp群发 | 明文（短暂，用于投递） | 完整内容（Meta） | 提供商保留 |
| Signal群发 | 明文（短暂，用于投递） | 通过Signal网络端对端加密 | 提供商不保留 |
| RCS群发 | 明文（短暂，用于投递） | Google可能看到内容 | 提供商保留 |

**这意味着**：群发消息不应包含敏感的来电者信息。用于公告和通知——不用于案例详情。

订阅者电话号码以哈希标识符形式存储——您的数据库从不包含明文订阅者列表。

### 笔记、转录和报告

志愿者编写的所有内容都经过端对端加密：

- 每条笔记使用**唯一随机密钥**（前向保密——泄露一条笔记不会泄露其他笔记）
- 密钥分别为志愿者和每位管理员封装
- 服务器只存储密文
- 解密在您的设备上进行，在一个安全层中，永远不会将密钥暴露给应用程序界面
- **自定义字段、报告内容和文件附件均单独加密**

**案例记录和实体数据**：结构化案例记录遵循相同的加密模型——每项使用唯一密钥加密。

**设备扣押**：没有您的PIN**和**对您的身份提供商账户的访问权限，攻击者只能获得受Argon2id保护的加密数据。如果您还使用硬件安全密钥，**三个独立因素**保护您的数据。

## 您的设备

### 查看和撤销设备

该应用程序保留了您登录过的每台设备的列表。您可以查看此列表并撤销任何您不认识的设备。

**撤销设备时：**
- 该设备立即被阻止访问您的账户
- 您的加密密钥轮换，以防被撤销的设备解密未来的内容
- 撤销记录在您账户的安全历史中

### SAS表情验证

对于有高安全需求的组织，管理员可以使用SAS（短认证字符串）验证来核实设备身份——显示为7个表情符号的序列。

**工作原理：**
1. 管理员和设备拥有者比较他们的表情序列（面对面、电话或通过可信渠道）
2. 如果表情匹配，设备被确认属于其注册拥有者
3. 验证被记录——管理员可以看到哪些设备已被验证

这可以防止攻击者在他人账户下注册假设备。表情序列来自两台设备的密码学身份密钥——服务器无法操纵或预测它。

## 账户注销

### 用户自助注销

您可以请求永久删除您的账户及其所有相关数据。默认情况下，在注销完成前有一个延迟期（由您的Hub管理员配置，通常为72小时）——这给您时间在被迫请求时取消。

**将被删除：**
- 您的设备密钥（使所有加密内容永久不可读，即使从备份中也是如此）
- 您的账户记录、角色分配和值班历史
- 您的推送通知令牌

**您创建的加密内容会怎样**：您编写的笔记和报告会为剩余授权读者重新加密。您的解密密钥副本被销毁。

**审计日志**：您的审计日志条目被"密码销毁"——每用户加密密钥被销毁，使您的条目不可读。哈希链（防篡改结构）保持完整。

### 紧急注销

如果您认为您的账户面临即时威胁，您可以请求与联合批准人进行紧急注销——将延迟减少到最少4小时。4小时下限的存在是为了防止强制删除（被迫在帮助到来前删除证据）。

## 恢复组

如果您丢失所有设备，您通常会失去对所有加密数据的访问权限。恢复组解决了这个问题。

### 恢复工作原理

您指定一组可信联系人（通常3-5人）作为您的恢复组。每位联系人持有恢复密钥的一个"片段"——拼图的一块。

**恢复您的账户：**
1. 您注册新设备并发起恢复请求
2. 您的恢复联系人收到通知
3. 经过可配置的延迟后，达到阈值数量的联系人（如3人中的2人）批准请求
4. 每位批准的联系人发送其片段，直接加密到您的新设备
5. 您的新设备组合片段以重建恢复密钥

**服务器可以看到什么**：服务器在设备间传递加密片段。它无法读取片段，也无法单独重建恢复密钥。

### 恢复组的安全属性

- **阈值安全性**：低于阈值的片段不会揭露秘密的任何信息
- **服务器不涉及秘密**：片段直接加密到您新设备的公钥
- **Hub范围**：恢复恢复您对特定Hub的访问
- **可取消的延迟**：您可以在延迟期内取消恢复请求
- **Signal验证**：恢复请求通过Signal验证

## 志愿者电话号码隐私

当志愿者在个人手机上接听来电时，他们的号码会暴露给您的电话运营商。

| 场景 | 电话号码可见给 |
|-----|-------------|
| PSTN通话到志愿者手机 | 电话运营商、移动运营商 |
| 浏览器对浏览器（WebRTC） | 无人（音频停留在浏览器中） |
| 自托管Asterisk + SIP电话 | 仅您的Asterisk服务器 |

**保护志愿者电话号码**：使用基于浏览器的通话（WebRTC）或提供连接到自托管Asterisk的SIP电话。

| 恢复组（Shamir） | 指定可信联系人，在您丢失所有设备时帮助恢复 |
| 诚实披露的群发消息 | 管理员可以发送群发消息；服务器短暂处理明文进行投递 |
| 订阅者哈希 | 订阅者电话号码以哈希标识符存储 |
| Argon2id密钥保护 | 设备密钥受内存密集函数保护 |
| Signal优先路由 | 可用时自动通过Signal路由消息 |
| 仅SMS通知模式 | SMS收件人只看到"您有新消息" |
| 流量分析抗性 | 事件大小被填充以防止观察者区分 |
| 数据库中无明文电话号码 | 来电者号码以不可逆哈希值存储 |
| 带前向保密的Hub加密 | 每24小时轮换一次密钥 |
| 所有平台使用Rust密码学 | 桌面、iOS和Android使用相同的经审计Rust密码库 |
| 受限中继访问 | WebSocket中继只接受来自您服务器的事件 |
| 加密消息存储 | SMS、WhatsApp和Signal以密文形式存储 |
| 设备端转录 | 音频永远不会离开您的设备 |
| 多因素密钥保护 | PIN、身份提供商及可选硬件安全密钥 |
| 硬件安全密钥 | 无法被远程攻击的第三因素 |
| 可重现构建 | 验证部署的代码与公开源代码一致 |
| 加密联系人目录 | 联系人记录、关系和笔记端对端加密 |

| 通话笔记 | 是（端对端） | 否 | 仅密文 |
| 转录 | 是（端对端） | 否 | 仅密文 |
| 报告 | 是（端对端） | 否 | 仅密文 |
| 案例记录/实体数据 | 是（端对端） | 否 | 仅密文 |
| 文件附件 | 是（端对端） | 否 | 仅密文 |
| 联系人记录 | 是（端对端） | 否 | 仅密文 |
| 志愿者身份 | 是（端对端） | 否 | 仅密文 |
| 团队/角色元数据 | 是（加密） | 否 | 仅密文 |
| 自定义字段定义 | 是（加密） | 否 | 仅密文 |
| 入站SMS/WhatsApp/Signal内容 | 是（在您的服务器上） | 否 | 服务器密文；提供商可能有原件 |
| 出站群发消息 | **否——投递时明文** | **是，短暂** | 是（发送时明文） |
