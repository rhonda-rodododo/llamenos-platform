**Markii ugu dambeysay la cusboonaysiiyay: May 4, 2026**

Llámenos waxaa sameeyay urur ku salaysan Midowga Yurub. Qodobka 17aad ee GDPR, waxaad xaq u leedahay inaad codsato tirtirista xogtaada shakhsiga ah. Boggani wuxuu sharxayaa sida loo sameeyo codsigaas iyo xogta la tirtiray ama la hayay.

---

## Sida Loogu Codsado Tirtirista Xogta

Waxaad codsan kartaa tirtirista akoonkaaga iyo dhammaan xogta la xiriirta iyada oo loo marayo mid ka mid ah hababdan:

### 1. Abka dhexdiisa (is-saacidda)

Tag **Settings → Account → Delete Account** gudaha abka Llámenos. Tani waxay isla markiiba saaraysaa akoonkaaga iyo dhammaan xogta la xiriirta xaruntaada.

### 2. Iyada oo loo marayo maamulaha xaruntaada

Maamulayaasha xaruntu waxay tirtiri karaan akoonada tabaruceyaasha iyo dhammaan xogta la xiriirta dariiqyada maamulka. La xiriir maamulaha xaruntaada oo weydii inay tirtiraan akoonkaaga.

### 3. Iimayl ahaan

Soo dir codsi [privacy@llamenos-platform.com](mailto:privacy@llamenos-platform.com) oo ay ku jiraan macluumaadkan:

- Magacaaga muujinta abka
- Magaca xarunta aad ka tirsan tahay (tusaale, ururka shaqeeya khadka gurmadka)

Codsiyada waa la farsameeyaa **30 maalmood** gudahood qodobka 17aad ee GDPR.

## Waxa La Tirtiro

Marka akoonkaaga la tirtiro, xogtan soo socota ayaa si joogto ah loo saaraa:

| Xogta | La tirtiray? |
|---|---|
| Aqoonsiyada akoonka iyo furayaasha qalabka | Haa — isla markiiba |
| Magaca muujinta iyo doorka | Haa — isla markiiba |
| Dhammaan qoraallada iyo warbixinada sirta ah ee aad qortay | Haa — qoraal sir ah waa laga saaray server-ka |
| Diiwaanada kiisaska iyo xiriirrada aad abuurtay | Haa — qoraal sir ah waa laga saaray server-ka |
| Calamada ogeysiiska riixista (FCM) | Haa — isla markiiba |
| Diiwaanada shifta iyo xogta helista | Haa — isla markiiba |
| Warbixinada burburka ee la xiriirta akoonkaaga | Haa — 30 maalmood gudahood |

## Waxa La Hayo (iyo Sababta)

Xoogaa xog ah ayaa la hayaa ka dib tirtirista sababo sharci iyo daacadnimo awgood:

### Diiwaannada hubinta — la qariyay, si aan xad lahayn loo hayaa

Llámenos wuxuu isticmaalaa diiwaan hubineed oo silsilad-hashyeedka caddayn-karista ah si uu u ogaado wax ka beddelka aan la oggoolayn ee diiwaanada dhaqdhaqaaqa. Tirtirista gelista shakhsi ahaaneed waxay jebin lahayd silsiladda waxayna hoos u dhigi lahayd dammaanadda daacadnimada.

**Waxa dhacay halkii:** Dhammaan aqoonsiyeyaasha shakhsiga ah ee diiwaannada hubinta ee kugu xusan (magacaaga muujinta, aqoonsiga akoonka) waxaa lagu beddelaa hash la qariyay. Dhacdada lafteeda (tusaale, "wicitaan laga jawaabay 14:32") waa la sii hayaa, laakiin lama xiriirin karo adiga ka dib qarinta.

**Muddada kaydinta:** Nolosha xarunta. Maamulaha xarunta ayaa kontoroola goorta diiwaanka hubinta xarunta la nadiifiyo.

### Tixraacyada ku jira nuxurka isticmaalayaasha kale — waa la qariyay

Haddii qoraallada sirta ah ee isticmaale kale ay kugu xusaan qayb ka mid ah wicitaanka, tixraacaas waa la qariyay (waxaa lagu beddelaa beddel). Nuxurka isticmaalaha kale lama tirtiro — waa kan iyaga.

## Soo Koobida Muddoyinka Kaydinta

| Nooca xogta | Kaydinta ka dib codsiga tirtirista |
|---|---|
| Akoonka, furayaasha, calamada | Isla markiiba waa la tirtiray |
| Qoraalada, warbixinada, farriimaha sirta ah | Waa la tirtiraa 30 maalmood gudahood |
| Warbixinada burburka | Waa la tirtiraa 30 maalmood gudahood |
| Nuqullada kaydka | Waa laga nadiifiyaa wareegga kaydka 90 maalmood gudahood |
| Diiwaannada hubinta | Isla markiiba waa la qariyay; silsiladda hashyada si aan xad lahayn ayaa loo hayaa |

---

## Qaadista Xogta

Ka hor inta aanad codsan tirtirista, waxaad dhoofin kartaa nuqul ka mid ah xogtaada. La xiriir maamulaha xaruntaada si aad u codsato dhoofin. Waxay ku siin karaan qoraalladaada, warbixinadaada, iyo macluumaadka akoonkaaga qaab qaabeysan.
