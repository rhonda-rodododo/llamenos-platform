**နောက်ဆုံးအပ်ဒိတ်- မေလ ၄၊ ၂၀၂၆**

Llámenos ကို EU-အခြေစိုက်အဖွဲ့အစည်းတစ်ခုကတီထွင်သည်။ GDPR ပုဒ်မ ၁၇ အရ သင်သည်သင့်ကိုယ်ရေးကိုယ်တာဒေတာကိုဖျက်ပစ်ရန်တောင်းဆိုပိုင်ခွင့်ရှိသည်။ ဤစာမျက်နှာသည်ထိုတောင်းဆိုချက်ကိုမည်သို့ပြုလုပ်ရမည်နှင့် မည်သည့်ဒေတာကိုဖျက်သည် သို့မဟုတ် ထိန်းသိမ်းသည်ကိုရှင်းပြသည်။

---

## ဒေတာဖျက်ခြင်းကိုမည်သို့တောင်းဆိုရမည်

အောက်ပါနည်းလမ်းများထဲမှတစ်ခုခုမှတစ်ဆင့် သင့်အကောင့်နှင့်ဆက်စပ်ဒေတာအားလုံးကိုဖျက်ရန်တောင်းဆိုနိုင်သည်-

### ၁။ အက်ပ်အတွင်း (ကိုယ်တိုင်လုပ်ဆောင်)

Llámenos အက်ပ်အတွင်းရှိ **ဆက်တင်များ → အကောင့် → အကောင့်ဖျက်ရန်** သို့သွားပါ။ ၎င်းသည်သင့်အကောင့်နှင့် ဆက်စပ်ဒေတာအားလုံးကို သင့် hub မှချက်ချင်းဖယ်ရှားသည်။

### ၂။ သင့် hub အက်ဒမင်မှတစ်ဆင့်

Hub အက်ဒမင်များသည် အက်ဒမင်အကန့်မှ စေတနာ့ဝန်ထမ်းအကောင့်များနှင့် ဆက်စပ်ဒေတာအားလုံးကိုဖျက်နိုင်သည်။ သင်ပိုင်ဆိုင်သော hub ၏အက်ဒမင်ကိုဆက်သွယ်ပြီး သင့်အကောင့်ကိုဖျက်ရန်တောင်းဆိုပါ။

### ၃။ အီးမေးလ်ဖြင့်

အောက်ပါအချက်အလက်များဖြင့် [privacy@llamenos-platform.com](mailto:privacy@llamenos-platform.com) သို့တောင်းဆိုချက်ပို့ပါ-

- အက်ပ်ရှိသင့်ဖော်ပြမည့်အမည်
- သင်ပိုင်ဆိုင်သော hub ၏အမည် (ဥပမာ၊ အရေးပေါ်လိုင်းကိုလည်ပတ်သည့်အဖွဲ့အစည်း)

တောင်းဆိုချက်များကို GDPR ပုဒ်မ ၁၇ အရ **ရက် ၃၀** အတွင်းဆောင်ရွက်သည်။

## ဖျက်ပစ်သည့်အရာများ

သင့်အကောင့်ကိုဖျက်သည့်အခါ အောက်ပါဒေတာကိုအပြီးတိုင်ဖယ်ရှားသည်-

| ဒေတာ | ဖျက်သလား။ |
|---|---|
| အကောင့်အထောက်အထားများနှင့်စက်ပစ္စည်းသော့များ | ဟုတ်သည် — ချက်ချင်း |
| ဖော်ပြမည့်အမည်နှင့်အခန်းကဏ္ဍ | ဟုတ်သည် — ချက်ချင်း |
| သင်ရေးသားခဲ့သောကုဒ်ဝှက်ထားသည့်မှတ်စုများနှင့်အစီရင်ခံစာများအားလုံး | ဟုတ်သည် — ciphertext ကိုဆာဗာမှဖျက်သည် |
| သင်ဖန်တီးခဲ့သောအမှုမှတ်တမ်းများနှင့်အဆက်အသွယ်မှတ်တမ်းများ | ဟုတ်သည် — ciphertext ကိုဆာဗာမှဖျက်သည် |
| Push အကြောင်းကြားချက် token (FCM) | ဟုတ်သည် — ချက်ချင်း |
| အလုပ်ချိန်မှတ်တမ်းများနှင့်ရရှိနိုင်မှုဒေတာ | ဟုတ်သည် — ချက်ချင်း |
| သင့်အကောင့်နှင့်ဆက်စပ်သောပျက်ကျမှုအစီရင်ခံစာများ | ဟုတ်သည် — ရက် ၃၀ အတွင်း |

## ထိန်းသိမ်းထားသည့်အရာများ (နှင့်အကြောင်းရင်း)

အချို့ဒေတာကိုဥပဒေရေးရာနှင့်ခိုင်မာမှုအကြောင်းပြချက်များအတွက်ဖျက်ပြီးနောက်ထိန်းသိမ်းထားသည်-

### စာရင်းစစ်မှတ်တမ်းများ — အမည်မဖော်ပြ၊ ရက်အကန့်အသတ်မရှိထိန်းသိမ်း

Llámenos သည် လုပ်ဆောင်ချက်မှတ်တမ်းများသို့ခွင့်ပြုချက်မရှိသောပြုပြင်မွမ်းမံမှုများကိုရှာဖွေရန် အနှောင့်အယှက်ရှာဖွေနိုင်သော hash-ကွင်းဆက်စာရင်းစစ်မှတ်တမ်းကိုအသုံးပြုသည်။ တစ်ဦးချင်းမှတ်တမ်းများကိုဖျက်ခြင်းသည်ကွင်းဆက်ကိုပျက်စီးစေပြီး ခိုင်မာမှုအာမခံချက်ကိုပျက်ပြားစေမည်။

**အစားထိုးဖြစ်ပျက်သည့်အရာ:** သင့်အားရည်ညွှန်းသောစာရင်းစစ်မှတ်တမ်းများရှိ ကိုယ်ရေးကိုယ်တာအညွှန်းအားလုံး (သင့်ဖော်ပြမည့်အမည်၊ အကောင့် ID) ကိုအမည်မဖော်သော hash ဖြင့်အစားထိုးသည်။ ဖြစ်ရပ်ကိုယ်တိုင် (ဥပမာ၊ "၁၄:၃၂ တွင်ခေါ်ဆိုမှုကိုဖြေကြားခဲ့သည်") ကိုထိန်းသိမ်းထားသော်လည်း ၎င်းကိုအမည်မဖော်ပြီးနောက်သင်နှင့်ပြန်လည်ချိတ်ဆက်၍မရနိုင်ပါ။

**ထိန်းသိမ်းကာလ:** hub ၏သက်တမ်းတစ်လျှောက်။ hub အက်ဒမင်က hub ၏စာရင်းစစ်မှတ်တမ်းကိုမည်သည့်အချိန်တွင်ရှင်းလင်းရမည်ကိုထိန်းချုပ်သည်။

### အခြားသုံးစွဲသူများ၏အကြောင်းအရာတွင်ရည်ညွှန်းချက်များ — အမည်မဖော်ပြ

အခြားသုံးစွဲသူတစ်ဦး၏ကုဒ်ဝှက်ထားသောမှတ်စုများကသင့်အားခေါ်ဆိုမှုပါဝင်သူအဖြစ်ရည်ညွှန်းပါက ထိုရည်ညွှန်းချက်ကိုအမည်မဖော်ပြ (နေရာယူသူဖြင့်အစားထိုး) သည်။ အခြားသုံးစွဲသူ၏အကြောင်းအရာကိုမဖျက်ပါ — ၎င်းသည်၎င်းတို့၏ပိုင်ဆိုင်မှုဖြစ်သည်။

| ဒေတာအမျိုးအစား | ဖျက်ရန်တောင်းဆိုပြီးနောက်ထိန်းသိမ်းမှု |
|---|---|
| အကောင့်၊ သော့များ၊ token များ | ချက်ချင်းဖျက်သည် |

| ပျက်ကျမှုအစီရင်ခံစာများ | ရက် ၃၀ အတွင်းဖျက်သည် |
| အရန်မိတ္တူများ | ရက် ၉၀ အတွင်းအရန်လည်ပတ်မှုမှဖယ်ရှားသည် |

## ဒေတာသယ်ယူနိုင်မှု

ဖျက်ရန်တောင်းဆိုခြင်းမပြုမီ သင်သည်သင့်ဒေတာမိတ္တူကိုထုတ်ယူနိုင်သည်။ ထုတ်ယူမှုတစ်ခုတောင်းဆိုရန် သင့် hub အက်ဒမင်ကိုဆက်သွယ်ပါ။ ၎င်းတို့သည်သင့်မှတ်စုများ၊ အစီရင်ခံစာများနှင့် အကောင့်အချက်အလက်များကိုဖွဲ့စည်းထားသောပုံစံဖြင့်ပေးနိုင်သည်။
