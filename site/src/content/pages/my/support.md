## မကြာခဏမေးလေ့ရှိသောမေးခွန်းများ

### စတင်ခြင်း

**Llámenos ဆိုတာဘာလဲ။**

Llámenos သည် လုံခြုံသောအကျပ်အတည်းတုံ့ပြန်ရေးအရေးပေါ်လိုင်းကိုလည်ပတ်ရန်အတွက် အခမဲ့အရင်းအမြစ်ဆော့ဖ်ဝဲဖြစ်သည်။ အဖွဲ့အစည်းများသည် ၎င်းတို့၏ကိုယ်ပိုင် hub ကိုကိုယ်တိုင်လက်ခံဆောင်ရွက်သည်။ တစ်စုံတစ်ယောက်ကသင့်အရေးပေါ်လိုင်းနံပါတ်ကိုခေါ်ဆိုသောအခါ တာဝန်ကျစေတနာ့ဝန်ထမ်းအားလုံးတစ်ပြိုင်နက်ခေါ်ဆိုသည် — ပထမဆုံးဖြေကြားသူကခေါ်ဆိုမှုကိုလက်ခံသည်။ စေတနာ့ဝန်ထမ်းများသည်ကုဒ်ဝှက်ထားသောမှတ်စုများကိုရေးသားသည်။ အက်ဒမင်များသည်အလုပ်ချိန်များ၊ စေတနာ့ဝန်ထမ်းများနှင့်ဆက်တင်များကိုစီမံသည်။

**Llámenos ကိုဘယ်သူလည်ပတ်သလဲ။**

အဖွဲ့အစည်းတစ်ခုစီသည် ၎င်းတို့၏ကိုယ်ပိုင် hub ကိုလည်ပတ်သည်။ ဗဟိုချုပ်ကိုင်ထားသော Llámenos cloud ဝန်ဆောင်မှုမရှိပါ။ iOS အက်ပ်သည် Llámenos-လည်ပတ်သောဆာဗာသို့မဟုတ်ဘဲ သင့်အဖွဲ့အစည်း၏ကိုယ်တိုင်လက်ခံဆောင်ရွက်ထားသော hub သို့ချိတ်ဆက်သည်။

**iOS အက်ပ်ကိုဘယ်လိုရနိုင်သလဲ။**

App Store မှ Llámenos ကိုဒေါင်းလုဒ်လုပ်ပါ။ ၎င်းကိုအသုံးပြုရန် hub တစ်ခု၏အက်ဒမင်ထံမှဖိတ်ကြားချက်တစ်ခုလိုအပ်သည်။ hub ချိတ်ဆက်မှုမရှိဘဲအက်ပ်ကိုအသုံးပြု၍မရပါ။

**ကျွန်ုပ်ဖိတ်ကြားချက်တစ်ခုရခဲ့သည် — ကျွန်ုပ်၏အကောင့်ကိုမည်သို့တည်ဆောက်ရမည်နည်း။**

သင့်စက်ပစ္စည်းပေါ်တွင်ဖိတ်ကြားချက်လင့်ခ်ကိုဖွင့်ပါ။ အက်ပ်သည် သင့်ကုဒ်ဝှက်ထားသောစက်ပစ္စည်းသော့များကိုဖန်တီးပြီး hub သို့ဝင်ရောက်ရန်လမ်းညွှန်ပေးလိမ့်မည်။ သင်သည် PIN တစ်ခုသတ်မှတ်ရန်လိုအပ်လိမ့်မည် — ဤ PIN သည်သင့်ကုဒ်ဝှက်သော့များကိုကာကွယ်ပေးပြီး မေ့သွားပါက ပြန်လည်မရယူနိုင်ပါ။

---

### ခေါ်ဆိုမှုများနှင့်အလုပ်ချိန်များ

**ကျွန်ုပ်တာဝန်ကျသော်လည်းခေါ်ဆိုမှုများမရရှိပါ။ ဘာမှားနေသလဲ။**

အောက်ပါတို့ကိုစစ်ဆေးပါ-
- သင်သည်အက်ပ်တွင်ရရှိနိုင်သည်ဟုမှတ်သားထားကြောင်း
- iOS ဆက်တင်များ → အကြောင်းကြားချက်များတွင် Llámenos အတွက် Push အကြောင်းကြားချက်များဖွင့်ထားကြောင်း
- သင့် hub အက်ဒမင်သည်တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူတစ်ဦးကိုဖွဲ့စည်းထားကြောင်း
- သင်သည်တက်ကြွသောအလုပ်ချိန်သို့မဟုတ်ခေါ်ဆိုမှုအဖွဲ့တွင်သတ်မှတ်ထားခြင်းခံရကြောင်း

အခြားအက်ပ်များအတွက်အကြောင်းကြားချက်များအလုပ်လုပ်သော်လည်း Llámenos အတွက်မဟုတ်ပါက push အကြောင်းကြားချက်ဖွဲ့စည်းမှုကိုအတည်ပြုရန်သင့် hub အက်ဒမင်ကိုဆက်သွယ်ပါ။

**ကျွန်ုပ်၏ကိုယ်ပိုင်ဖုန်းနံပါတ်တွင်ခေါ်ဆိုမှုများကိုလက်ခံနိုင်ပါသလား။**

ပုံမှန်အားဖြင့် ခေါ်ဆိုမှုများကိုအက်ပ်သို့ push အကြောင်းကြားချက်များအဖြစ်ပို့သည်။ သင့်အက်ဒမင်က PSTN အရန် (အမှန်တကယ်ဖုန်းနံပါတ်သို့လွှဲပို့ခြင်း) ကိုဖွင့်ထားပါက သင့်ကိုယ်ရေးကိုယ်တာနံပါတ်သည်တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူအားထုတ်ဖော်ခံရလိမ့်မည်။ မည်သည့် mode ကိုဖွဲ့စည်းထားသည်ကိုသင့်အက်ဒမင်ကိုမေးမြန်းပါ။

**ခေါ်ဆိုမှုကိုမည်သူမျှမဖြေကြားပါကဘာဖြစ်မည်နည်း။**

ဖွဲ့စည်းထားသောအချိန်ကုန်လွန်ပြီးနောက် ခေါ်ဆိုမှုသည်အသံမေးလ် (ဖွဲ့စည်းထားပါက) သို့သွားသည် သို့မဟုတ် ပြတ်တောက်သွားသည်။ သင့်အက်ဒမင်သည် hub ဆက်တင်များတွင်အရန်အပြုအမူကိုဖွဲ့စည်းနိုင်သည်။

### ကိုယ်ရေးလုံခြုံမှုနှင့်ကုဒ်ဝှက်ခြင်း

**ဆာဗာသည်ကျွန်ုပ်၏မှတ်စုများကိုဖတ်နိုင်ပါသလား။**

မဖတ်နိုင်ပါ။ မှတ်စုများ၊ စကားဝိုင်းမှတ်တမ်းများ၊ အစီရင်ခံစာများနှင့် မက်ဆေ့ချ်များသည်အဆုံးမှအဆုံးကုဒ်ဝှက်ထားသည်။ ဆာဗာသည် ciphertext ကိုသာသိမ်းဆည်းသည်။ သင့် hub အော်ပရေတာသည်အကြောင်းအရာကိုမဖတ်နိုင်ပါ။ နည်းပညာအသေးစိတ်အတွက်ကျွန်ုပ်တို့၏ [ကိုယ်ရေးလုံခြုံမှုမူဝါဒ](/privacy) နှင့် [လုံခြုံရေးစာမျက်နှာ](/security) ကိုကြည့်ပါ။

**ကျွန်ုပ်၏ PIN ကိုမေ့သွားပါကဘာဖြစ်မည်နည်း။**

သင့် PIN သည်သင့်ကုဒ်ဝှက်သော့များကိုကာကွယ်ပေးသည်။ ၎င်းကိုမေ့သွားပါက သင့်ကုဒ်ဝှက်ထားသောဒေတာကိုပြန်လည်မရယူနိုင်ပါ — ၎င်းသည်လုံခြုံရေးအင်္ဂါရပ်တစ်ခုဖြစ်သည်၊ bug မဟုတ်ပါ။ သင့်အကောင့်ကိုပြန်လည်သတ်မှတ်ရန်သင့် hub အက်ဒမင်ကိုဆက်သွယ်ပါ။ သင်သည်သင့်အကောင့်မှယခင်ကုဒ်ဝှက်ထားသောမှတ်စုများကိုဝင်ရောက်ခွင့်ဆုံးရှုံးလိမ့်မည်။

**ကျွန်ုပ်၏ခေါ်ဆိုမှုအသံကိုမှတ်တမ်းတင်ထားပါသလား။**

မှတ်တမ်းတင်ခြင်းကိုပုံမှန်အားဖြင့်ပိတ်ထားသည်။ သင့်အက်ဒမင်ကမှတ်တမ်းတင်ခြင်းကိုဖွင့်ထားပါက ၎င်းတို့သည်စေတနာ့ဝန်ထမ်းများအားထုတ်ဖော်ပြောကြားရမည်။ ဘရောက်ဆာအတွင်းစကားဝိုင်းမှတ်တမ်းသည် စက်ပေါ်ရှိ AI ကိုအသုံးပြုသည် — အသံသည်သင့်စက်ပစ္စည်းမှဘယ်တော့မျှမထွက်ခွာပါ။

### နည်းပညာပြဿနာများ

**အက်ပ်က "hub သို့ချိတ်ဆက်၍မရ" ဟုပြသည်။ ကျွန်ုပ်ဘာလုပ်သင့်သနည်း။**

၁။ သင့်အင်တာနက်ချိတ်ဆက်မှုကိုစစ်ဆေးပါ
၂။ သင့် hub အက်ဒမင်တွင်ဆာဗာအလုပ်လုပ်နေကြောင်းအတည်ပြုပါ
၃။ အက်ပ်ကိုပိတ်ပြီးပြန်ဖွင့်ကြည့်ပါ
၄။ ပြဿနာဆက်လက်ရှိနေပါက အက်ပ်၏ရောဂါရှာဖွေရေးမျက်နှာပြင်မှအမှားသတင်းစကားဖြင့်သင့် hub အက်ဒမင်ကိုဆက်သွယ်ပါ

**bug တစ်ခုကိုမည်သို့အစီရင်ခံရမည်နည်း။**

[github.com/rhonda-rodododo/llamenos-platform/issues](https://github.com/rhonda-rodododo/llamenos-platform/issues) တွင်ပြဿနာတစ်ခုဖွင့်ပါ။ အောက်ပါတို့ထည့်သွင်းပါ-
- iOS ဗားရှင်းနှင့်စက်ပစ္စည်းမော်ဒယ်
- အက်ပ်ဗားရှင်း (ဆက်တင်များ → အကြောင်းတွင်)
- ပြဿနာကိုပြန်လည်ထုတ်လုပ်ရန်အဆင့်များ
- သင်မျှော်လင့်ထားသည်နှင့်အမှန်တကယ်ဖြစ်ပျက်ခဲ့သည်ကို
- ပြသထားသည့်အမှားသတင်းစကားများ

**လုံခြုံရေးအားနည်းချက်တစ်ခုတွေ့ရှိခဲ့သည်။ ၎င်းကိုမည်သို့အစီရင်ခံရမည်နည်း။**

GitHub ၏ကိုယ်ရေးလုံခြုံမှုရှိသော လုံခြုံရေးအကြံပေးအင်္ဂါရပ်ကိုအသုံးပြုပါ: [github.com/rhonda-rodododo/llamenos-platform/security/advisories/new](https://github.com/rhonda-rodododo/llamenos-platform/security/advisories/new)။ လုံခြုံရေးအားနည်းချက်များအတွက်အများသုံးပြဿနာကိုမဖွင့်ပါနှင့်။

### အက်ဒမင်များအတွက်

**hub တစ်ခုကိုမည်သို့ကိုယ်တိုင်လက်ခံဆောင်ရွက်ရမည်နည်း။**

[ဖြန့်ကျက်မှုလမ်းညွှန်](/docs/deploy) ကိုကြည့်ပါ။ Llámenos သည် ပုံမှန် Linux VPS ပေါ်တွင် Docker Compose မှတစ်ဆင့်အလုပ်လုပ်သည်။ အနည်းဆုံးလိုအပ်ချက်များ: 2 vCPU, 2 GB RAM, PostgreSQL 16 ။

**ကျွန်ုပ်၏ hub သို့စေတနာ့ဝန်ထမ်းများကိုမည်သို့ထည့်ရမည်နည်း။**

အက်ဒမင်အကန့်တွင်၊ စေတနာ့ဝန်ထမ်းများ → ဖိတ်ကြားရန် သို့သွားပါ။ ဖိတ်ကြားချက်လင့်ခ်တစ်ခုထုတ်ပြီး စေတနာ့ဝန်ထမ်းအားလုံခြုံစွာမျှဝေပါ။ လင့်ခ်သည်တစ်ကြိမ်သုံးဖြစ်ပြီးသက်တမ်းကုန်သည်။

**မည်သည့်တယ်လီဖုန်းဝန်ဆောင်မှုပေးသူများကိုပံ့ပိုးထားသနည်း။**

Twilio, SignalWire, Vonage, Plivo, Telnyx, Bandwidth, Asterisk နှင့် FreeSWITCH ။ ဝန်ဆောင်မှုပေးသူတစ်ဦးစီအတွက်ဖွဲ့စည်းမှုညွှန်ကြားချက်များအတွက်အက်ဒမင်လမ်းညွှန်ကိုကြည့်ပါ။

**လက်ခံဆောင်ရွက်ပေးသော/စီမံခန့်ခွဲသောဗားရှင်းရှိပါသလား။**

လောလောဆယ်မရှိပါ။ Llámenos သည်ကိုယ်တိုင်လက်ခံဆောင်ရွက်သောဆော့ဖ်ဝဲဖြစ်သည်။ ကျွန်ုပ်တို့သည် ၎င်းတို့၏ကိုယ်ပိုင်အခြေခံအဆောက်အအုံကိုမလည်ပတ်နိုင်သောအဖွဲ့အစည်းများအတွက်စီမံခန့်ခွဲသောဟော့စတင်ရွေးချယ်မှုများကိုရှာဖွေနေသည် — ၎င်းသည်သင့်အဖွဲ့အစည်းအတွက်အတားအဆီးတစ်ခုဖြစ်ပါက [support@llamenos-platform.com](mailto:support@llamenos-platform.com) သို့ဆက်သွယ်ပါ။
