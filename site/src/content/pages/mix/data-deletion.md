**Última actualización: 4 mayo 2026**

Llámenos es desarrollado por organización basada EU. Bajo Artículo 17 GDPR, tiene derecho solicitar borrado datos personales. Yaa página explica cómo hacer solicitud ni qué datos se eliminan o retienen.

---

## Cómo Solicitar Eliminación Datos

Puede solicitar eliminación cuenta ni todos datos asociados a través cualquiera métodos siguientes:

### 1. Nu app (autoservicio)

Vaya a **Configuración → Cuenta → Eliminar Cuenta** dentro app Llámenos. Yaa elimina inmediatamente cuenta ni todos datos asociados hub.

### 2. Vía administrador hub

Ña'as hubs pueden eliminar cuentas voluntarios ni todos datos asociados desde panel ña'a. Contacte administrador hub pertenece ni pídale eliminar cuenta.

### 3. Por correo

Envíe solicitud a [privacy@llamenos-platform.com](mailto:privacy@llamenos-platform.com) nuu información siguiente:

- Nombre visible nuu app
- Nombre hub pertenece (ej., organización operando línea caliente)

Solicitudes procesadas dentro **30 días** según Artículo 17 GDPR.

---

## Qué Se Elimina

Cuando cuenta eliminada, siguientes datos permanentemente removidos:

| Datos | ¿Eliminado? |
|------|----------|
| Credenciales cuenta ni claves dispositivo | Saa — inmediatamente |
| Nombre visible ni rol | Saa — inmediatamente |
| Todas notas ni reportes cifrados autorados | Saa — ciphertext eliminado servidor |
| Registros caso ni contacto creados | Saa — ciphertext eliminado servidor |
| Token notificación push (FCM) | Saa — inmediatamente |
| Registros turnos ni datos disponibilidad | Saa — inmediatamente |
| Reportes fallos asociados cuenta | Saa — dentro 30 días |

---

## Qué Se Retiene (ni Por Qué)

Algunos datos retienen después eliminación nuu razones legales ni integridad:

### Entradas log auditoría — anonimizadas, retenidas indefinidamente

Llámenos usa log auditoría cadena hash evidencia manipulación nuu detectar modificaciones no autorizadas registros actividad. Eliminar entradas individuales rompería cadena ni socavaría garantía integridad.

**Qué pasa en lugar**: Todos identificadores personales nuu entradas log auditoría referenciándole (nombre visible, ID cuenta) reemplazados por hash anonimizado. Evento mismo (ej., "llamada respondida 14:32") retenido, pero no puede vincularse a usted después anonimización.

**Período retención**: Vida hub. Administrador hub controla cuándo log auditoría hub purgado.

### Referencias nuu contenido otros usuarios — anonimizadas

Si notas cifradas otro usuario referencianle como participante llamada, yaa referencia anonimizada (reemplazada placeholder). Contenido otro usuario no eliminado — pertenece a ellos.

---

## Resumen Períodos Retención

| Tipo datos | Retención después solicitud eliminación |
|-----------|----------------------------------|
| Cuenta, claves, tokens | Eliminado inmediatamente |
| Notas cifradas, reportes, mensajes | Eliminado dentro 30 días |
| Reportes fallos | Eliminado dentro 30 días |
| Copias respaldo | Purgado rotación respaldo dentro 90 días |
| Entradas log auditoría | Anonimizado inmediatamente; cadena hash retenida indefinidamente |

---

## Portabilidad Datos

Antes solicitar eliminación, puede exportar copia datos. Contacte administrador hub nuu solicitar exportación. Pueden proporcionar notas, reportes, ni información cuenta nuu formato estructurado.
