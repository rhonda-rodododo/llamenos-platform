## 호스팅 제공업체가 소환장을 받는 경우

| 제공 가능 | 제공 불가능 |
|----------|-----------|
| 통화/메시지 메타데이터 (시간, 지속 시간) | 메모 내용, 녹취록, 보고서 본문 |
| 암호화된 데이터베이스 블롭 | 자원봉사자 이름 (종단간 암호화) |
| 어떤 자원봉사자 계정이 언제 활성화되었는지 | 연락처 디렉토리 기록 (종단간 암호화) |
| 대량 메시지 배달 기록 | 메시지 내용 (도착 시 암호화, 암호문으로 저장) |
| | 복호화 키 (PIN, 신원 제공업체, 선택적으로 하드웨어 보안 키로 보호) |
| | 노트별 암호화 키 (임시 — 래핑 후 삭제) |
| | 전화번호 해시를 역추적하기 위한 HMAC 비밀 |
| | 복구 조각 내용 (암호화됨, 서버가 읽을 수 없음) |

**서버는 읽을 수 없는 데이터를 저장합니다.** 메타데이터(언제, 얼마나, 어떤 계정)는 볼 수 있습니다. 내용(무슨 말을 했는지, 무엇을 썼는지, 연락처가 누구인지)은 볼 수 없습니다.

## 기능별

개인정보 노출 수준은 어떤 채널을 활성화했느냐에 따라 달라집니다:

### 음성 통화

| 사용하는 경우... | 제3자 접근 가능 | 서버 접근 가능 | 종단간 암호화 내용 |
|----------------|---------------|--------------|-----------------|
| Twilio/SignalWire/Vonage/Plivo | 통화 오디오 (라이브), 통화 기록 | 통화 메타데이터 | 메모, 녹취록 |
| 자체 호스팅 Asterisk | 없음 (직접 제어) | 통화 메타데이터 | 메모, 녹취록 |
| 브라우저-대-브라우저 (WebRTC) | 없음 | 통화 메타데이터 | 메모, 녹취록 |

**전화 제공업체에 대한 소환장**: 통화 상세 기록(시간, 번호, 지속 시간)이 있습니다. 통화 메모나 녹취록은 없습니다. 녹음은 기본적으로 비활성화되어 있습니다.

**녹취**: 녹취는 로컬 AI를 사용하여 브라우저에서 완전히 이루어집니다. **오디오는 기기를 벗어나지 않습니다.**

### 문자 메시지 (일대일)

| 채널 | 제공업체 접근 | 서버 저장 | 비고 |
|-----|------------|---------|-----|
| SMS | 전화 제공업체가 모든 메시지를 읽음 | **암호화** | 제공업체가 원본 메시지 보유 |
| WhatsApp | Meta가 모든 메시지를 읽음 | **암호화** | 제공업체가 원본 메시지 보유 |
| Signal | Signal 네트워크는 E2EE; 브리지가 도착 시 재암호화 | **암호화** | 사용 가능 시 선호 경로 |

**Signal 우선 라우팅**: 수신자가 Signal을 사용하면 메시지가 자동으로 Signal을 통해 라우팅됩니다. SMS의 경우 기본적으로 일반 알림만 전송됩니다 (메시지 본문 없음).

**메시지는 서버에 도착하는 즉시 암호화됩니다.** 서버는 암호문만 저장합니다.

### 대량 및 브로드캐스트 메시지

관리자는 SMS, WhatsApp, Signal 또는 RCS를 통해 구독자에게 대량 메시지를 보낼 수 있습니다.

**중요: 발신 대량 메시지는 서버에서 종단간 암호화되지 않습니다.** SMS 또는 WhatsApp 구독자에게 메시지를 전달하려면 서버가 잠시 동안 일반 텍스트 콘텐츠를 처리하여 메시지 제공업체에 전달해야 합니다.

| 채널 | 전송 시 서버 접근 | 제공업체 접근 | 전달 후 |
|----|----------------|------------|--------|
| SMS 대량 | 일반 텍스트 (잠시, 전달 목적) | 전체 내용 | 제공업체 보유 |
| WhatsApp 대량 | 일반 텍스트 (잠시, 전달 목적) | 전체 내용 (Meta) | 제공업체 보유 |
| Signal 대량 | 일반 텍스트 (잠시, 전달 목적) | Signal 네트워크를 통한 E2EE | 제공업체 미보유 |
| RCS 대량 | 일반 텍스트 (잠시, 전달 목적) | Google이 내용 볼 수 있음 | 제공업체 보유 |

**무슨 의미인가요**: 대량 메시지에는 민감한 발신자 정보가 포함되어서는 안 됩니다. 공지사항과 알림에 사용하세요 — 사례 세부사항에는 사용하지 마세요.

구독자 전화번호는 해시된 식별자로 저장됩니다 — 데이터베이스에 일반 텍스트 구독자 목록이 포함되지 않습니다.

### 메모, 녹취록 및 보고서

자원봉사자가 작성한 모든 내용은 종단간 암호화됩니다:

- 각 메모는 **고유한 무작위 키** 사용 (순방향 비밀 — 하나의 메모를 침해해도 다른 메모에 영향 없음)
- 키는 자원봉사자와 각 관리자를 위해 별도로 래핑됩니다
- 서버는 암호문만 저장합니다
- 복호화는 기기에서 이루어지며, 키가 앱 인터페이스에 노출되지 않는 보안 레이어에서 처리됩니다
- **사용자 정의 필드, 보고서 내용 및 파일 첨부 파일은 모두 개별적으로 암호화됩니다**

**사례 기록 및 엔티티 데이터**: 동일한 암호화 모델을 따릅니다 — 각 항목이 고유한 키로 암호화됩니다.

**기기 압수**: PIN **및** 신원 제공업체 계정에 대한 접근 없이는 공격자가 Argon2id로 보호된 암호화된 블롭만 얻습니다. 하드웨어 보안 키를 사용하면 **세 가지 독립적인 요소**가 데이터를 보호합니다.

## 기기 관리

### 기기 보기 및 취소

앱은 로그인한 모든 기기 목록을 유지합니다. 이 목록을 보고 알 수 없는 기기를 취소할 수 있습니다.

**기기를 취소할 때:**
- 해당 기기는 즉시 계정 접근이 차단됩니다
- 취소된 기기가 향후 콘텐츠를 복호화할 수 없도록 암호화 키가 교체됩니다
- 취소 사항이 계정 보안 기록에 기록됩니다

### SAS 이모지 인증

높은 보안 요구사항을 가진 조직의 경우 관리자는 SAS (짧은 인증 문자열) 인증을 사용하여 기기 신원을 확인할 수 있습니다 — 7개의 이모지 시퀀스로 표시됩니다.

**작동 방식:**
1. 관리자와 기기 소유자가 이모지 시퀀스를 비교합니다 (직접, 전화 또는 신뢰할 수 있는 채널을 통해)
2. 이모지가 일치하면 기기가 등록된 소유자에게 속한 것으로 확인됩니다
3. 인증이 기록됩니다 — 관리자가 어떤 기기가 인증되었는지 볼 수 있습니다

이것은 다른 사람의 계정으로 가짜 기기를 등록한 공격자로부터 보호합니다.

## 계정 삭제

### 사용자 직접 삭제

계정과 모든 관련 데이터의 영구 삭제를 요청할 수 있습니다. 기본적으로 삭제가 완료되기 전에 지연이 있습니다 (허브 관리자가 구성, 일반적으로 72시간) — 강압에 의한 요청인 경우 취소할 시간을 줍니다.

**삭제되는 것:**
- 기기 키 (백업에서도 암호화된 모든 콘텐츠를 영구적으로 읽을 수 없게 함)
- 계정 기록, 역할 할당 및 교대 기록
- 푸시 알림 토큰

**만든 암호화 콘텐츠는 어떻게 됩니까**: 작성한 메모와 보고서는 남은 승인된 독자를 위해 재암호화됩니다. 복호화 키 사본이 삭제됩니다.

**감사 로그**: 감사 로그 항목이 "암호 삭제"됩니다 — 사용자별 암호화 키가 삭제되어 항목을 읽을 수 없게 됩니다. 해시 체인은 그대로 유지됩니다.

### 긴급 삭제

계정이 즉각적인 위협에 처했다고 생각하면 공동 승인자와 함께 긴급 삭제를 요청할 수 있습니다 — 지연을 최소 4시간으로 줄입니다. 4시간 최소 기준은 강제 삭제(도움이 오기 전에 증거를 삭제하도록 강요)로부터 보호하기 위해 존재합니다.

## 복구 그룹

모든 기기를 잃으면 일반적으로 모든 암호화된 데이터에 대한 접근 권한을 잃게 됩니다. 복구 그룹이 이를 해결합니다.

### 복구 작동 방식

신뢰할 수 있는 연락처 그룹 (일반적으로 3-5명)을 복구 그룹으로 지정합니다. 각 연락처는 복구 키의 "조각"을 보유합니다.

**계정을 복구하려면:**
1. 새 기기를 등록하고 복구 요청을 시작합니다
2. 복구 연락처가 알림을 받습니다
3. 구성 가능한 지연 후 임계값 수의 연락처 (예: 3명 중 2명)가 요청을 승인합니다
4. 각 승인 연락처가 새 기기에 직접 암호화된 자신의 조각을 보냅니다
5. 새 기기가 조각을 결합하여 복구 키를 재구성합니다

**서버가 볼 수 있는 것**: 서버는 기기 간에 암호화된 조각을 전달합니다. 조각을 읽거나 복구 키를 스스로 재구성할 수 없습니다.

### 복구 그룹의 보안 속성

- **임계값 보안**: 임계값 미만의 조각은 비밀에 대한 정보를 드러내지 않습니다
- **서버가 비밀에 관여하지 않음**: 조각은 새 기기의 공개 키에 직접 암호화됩니다
- **허브 범위**: 복구는 특정 허브에 대한 접근을 복원합니다
- **취소 가능한 지연**: 지연 기간 동안 복구 요청을 취소할 수 있습니다
- **Signal 인증**: 복구 요청은 Signal을 통해 인증됩니다

## 자원봉사자 전화번호 개인정보

자원봉사자가 개인 전화로 전화를 받을 때 번호가 전화 제공업체에 노출됩니다.

| 시나리오 | 전화번호 공개 대상 |
|---------|----------------|
| 자원봉사자 전화로 PSTN 통화 | 전화 제공업체, 이동통신사 |
| 브라우저-대-브라우저 (WebRTC) | 없음 (오디오가 브라우저에 유지됨) |
| 자체 호스팅 Asterisk + SIP 전화 | Asterisk 서버만 |

**자원봉사자 전화번호 보호**: 브라우저 기반 통화(WebRTC)를 사용하거나 자체 호스팅 Asterisk에 연결된 SIP 전화를 제공하세요.

| 기능 | 개인정보 보호 혜택 |

| SAS 이모지 기기 인증 | 관리자가 7개 이모지의 암호화 지문으로 직접 기기를 인증할 수 있음 |
| 지연이 있는 계정 삭제 | 삭제 요청; 구성 가능한 지연으로 강압 시 취소 가능 |

| 복구 그룹 (Shamir) | 모든 기기를 잃으면 복구를 도울 수 있는 신뢰할 수 있는 연락처 지정 |
| 정직한 공개를 포함한 대량 메시지 | 관리자가 대량 메시지를 보낼 수 있음; 서버가 전달을 위해 일반 텍스트를 잠시 처리 |
| 구독자 해싱 | 구독자 전화번호가 해시된 식별자로 저장됨 |
| Argon2id 키 보호 | 메모리 집약적 함수로 보호된 기기 키 |
| Signal 우선 라우팅 | 사용 가능 시 Signal을 통해 자동으로 메시지 라우팅 |
| SMS 알림 전용 모드 | SMS 수신자는 "새 메시지가 있습니다"만 볼 수 있음 |
| 트래픽 분석 저항 | 이벤트 크기가 패딩되어 관찰자가 구별할 수 없음 |
| 데이터베이스에 일반 텍스트 전화번호 없음 | 발신자 번호가 되돌릴 수 없는 해시로 저장됨 |
| 순방향 비밀을 포함한 허브별 암호화 | 24시간마다 키 교체 |
| 모든 플랫폼에서 Rust 암호화 | 데스크탑, iOS 및 Android에서 동일한 감사된 Rust 암호화 라이브러리 |
| 제한된 릴레이 접근 | WebSocket 릴레이가 서버에서만 이벤트를 수락 |
| 암호화된 메시지 저장 | SMS, WhatsApp 및 Signal이 암호문으로 저장됨 |
| 기기 전사 | 오디오가 기기를 떠나지 않음 |
| 다중 요소 키 보호 | PIN, 신원 제공업체 및 선택적 하드웨어 보안 키 |
| 하드웨어 보안 키 | 원격으로 침해될 수 없는 세 번째 요소 |
| 재현 가능한 빌드 | 배포된 코드가 공개 소스와 일치하는지 확인 |
| 암호화된 연락처 디렉토리 | 연락처 기록, 관계 및 메모가 종단간 암호화됨 |

| 보고서 | 예 (종단간) | 아니오 | 암호문만 |
| 사례 기록 / 엔티티 데이터 | 예 (종단간) | 아니오 | 암호문만 |
| 파일 첨부 | 예 (종단간) | 아니오 | 암호문만 |
| 연락처 기록 | 예 (종단간) | 아니오 | 암호문만 |
| 자원봉사자 신원 | 예 (종단간) | 아니오 | 암호문만 |
| 팀/역할 메타데이터 | 예 (암호화됨) | 아니오 | 암호문만 |
| 사용자 정의 필드 정의 | 예 (암호화됨) | 아니오 | 암호문만 |
| 수신 SMS/WhatsApp/Signal 내용 | 예 (서버에서) | 아니오 | 서버 암호문; 제공업체에 원본 있을 수 있음 |
| 발신 대량 메시지 | **아니오 — 전달 중 일반 텍스트** | **예, 잠시** | 예 (전송 시 일반 텍스트) |
| 복구 조각 | 예 (기기에 종단간) | 아니오 | 암호문만 |
| 실시간 이벤트 | 예 (허브별, 교체 키) | 아니오 | 암호문만 |
| 통화 메타데이터 | 아니오 | 예 | 예 |
| 대량 전달 기록 | 아니오 | 예 | 예 |

| User-Agent 문자열 | SHA-256 해시 | 해시만 | 해시 (역추적 불가) |
